# مارپیچ صنعت

## تکمیل نسخهٔ ۶ اکتبر

منوی مشترک در تمام اندازه‌ها بعد از ۶۰۰px اسکرول ثابت می‌شود. ردیف همبرگریِ ثابت، ۸px پدینگ بالا و پایین دارد. تغییر آستانه از کنترل «آستانهٔ اسکرول» در کاستومایزر امکان‌پذیر است.

اصلاح تصویر و Badge فقط در `src/css/pages/industries.css` قرار دارد؛ عنوان «صنایع تحت پوشش» بالای کارت‌ها در عرض‌های تا ۶۳۹px برابر ۲۲px است. فایل‌های گرید محصولات و تنظیمات ذخیره‌شده تغییر نکرده‌اند.

برای جایگزینی نسخه، محتویات ZIP را کنار `package.json` فعلی Merge/Replace کن و پوشه‌های تصویر، فونت، `docs` و خروجی‌های موجود را حفظ کن. ابزار پاکسازی اکنون فهرست خود را از `scripts/legacy-files.json` می‌خواند و به پوشهٔ مستندات وابسته نیست.

```powershell
npm run check
npm run publish:github
```

اصلاح انتشار روی ویندوز: مسیرهای فایل و LF/CRLF در مرجع متغیرها یکسان‌سازی شده‌اند؛ تنظیمات ذخیره‌شدهٔ کاستومایزر وارد قرارداد سورس نمی‌شوند. اجرای npm بدون `shell:true` انجام می‌شود. ظاهر سایت، پترن‌ها و تنظیمات نسخهٔ قبلی حفظ شده‌اند. راهنمای پچ و دو دستور انتشار در [WINDOWS-PUSH-FIX.md](WINDOWS-PUSH-FIX.md) است.

در این اصلاح V3، پترن با حداقل ضخامت پیکسلی قابل تنظیم و حرکت آرام‌تر نمایش داده می‌شود. داخل کاستومایزر، راهنمای رفع بریدگی و گزینه‌های «حرکت ملایم» و «فقط نور» اضافه شده‌اند. منوی ثابت همبرگری بدون فاصله و با ورود کوتاه است؛ تصاویر، فرآیند همکاری و تزئینات در نمایشگر بزرگ از قاب ۱۹۲۰px پیروی می‌کنند. راهنمای دقیق در `CUSTOMIZER.md` است.
این نسخه اجرای پیوستهٔ پترن هدر/فوتر، سقف عرض ۱۹۲۰px برای محتوای نمایشگرهای بزرگ و منوی ثابت با تنظیمات مستقل صفحه و اندازه دارد. در کاستومایزر از «منوی ثابت» استفاده کن؛ راهنمای کامل فیلدها در `CUSTOMIZER.md` است. دو پترن ثابتِ جدید دسکتاپ نیازمند ارسال فایل طرح‌ها هستند.

نسخهٔ V3 (`3.0.0`) — اصلاحات ۵ اکتبر ۲۰۲۶ بر مبنای آخرین بستهٔ تحویلی `312231.zip`: پیوستگی موج پترن، راهنمای همهٔ فیلدهای پترن، ویرایش مستقیم متغیرها و خط CTA فقط با هاور یا فوکوس خودِ دکمه. گرید محصولات و کنترل تصویر درباره‌ما حفظ شده‌اند. آپدیت معمولی روی `main` انجام می‌شود و tag قبلی `v3` حفظ می‌شود؛ راهنما در `GITHUB-UPLOAD.md` است. تغییرات در [CHANGELOG.md](CHANGELOG.md) آمده‌اند.

HTML، Tailwind CSS 4، ES Modules و Vite؛ کامپوننت‌های HTML در زمان Build ترکیب می‌شوند. فریم‌ورک UI اضافه نشده است.

## جایگزینی این بسته

1. محتوای ZIP را در پوشهٔ اصلی پروژه کنار `package.json`، Merge و Replace کن.
2. پوشه‌های `assets`، `public` و فونت‌های قبلی را نگه دار. این بسته جایگزین تصاویر اصلی نیست.
3. فایل‌های قدیمی مشخص‌شده را حذف کن:

```bash
npm run clean:legacy -- --apply
npm ci
npm run check
npm run customize
```

`clean:legacy` فقط فهرست صریح `docs/obsolete-files.json` را حذف می‌کند؛ بدون `--apply` فقط فهرست را نمایش می‌دهد. نیازی به پاک‌کردن دستی پوشه‌ها نیست.

Node.js حداقل 22.12.0 لازم است. در ویندوز `CUSTOMIZE.cmd` نیز همان ویرایشگر را اجرا و وابستگی‌های قدیمی را اصلاح می‌کند. برای اجرای عادی: `npm run dev`. بازکردن HTML با دوبار کلیک یا Live Server، includeها را پردازش نمی‌کند.

## Customizer

مسیر محلی: `/tools/customizer.html`. بخش مشترک یا المان دقیق را انتخاب کن، محدودهٔ صفحه و اندازه را مشخص کن و مقادیر را تغییر بده. بازه‌های دلخواه، واحدهای CSS، Grid/Flex، موقعیت، رنگ، سایه، hover/focus، پترن‌ها، Undo/Redo، کپی تنظیمات و مدیریت قانون‌ها قابل ویرایش‌اند.

عرض پیش‌نمایش با کشیدن لبه‌های چپ و راست تغییر می‌کند. دکمه‌های «هدر» و «هیرو» تنظیم مستقل همین صفحه را باز می‌کنند. «پیش‌نمایش در تب جدید» تغییرات ثبت‌نشده را همراه با جابه‌جایی بین صفحات نشان می‌دهد. تگ روی تصویر و تگ مشخصات پایین، کلاس و کنترل جدا دارند؛ پدینگ بالای تگ پایین 8px است.

زوم دستی 25 تا 200٪ و «جا شدن در قاب» فقط نمایش ویرایشگر را تغییر می‌دهند؛ عرض و ارتفاع واقعی iframe و media queryها ثابت می‌مانند. صفحهٔ راهنمای متغیرها در `/tools/design-tokens.html` است. تب «راهنمای متغیرها» مقدار زنده و فرم ویرایش همان متغیر را نشان می‌دهد. ۱۸۲ متغیر با محدودهٔ صفحه و بازهٔ اندازه، اعمال در پیش‌نمایش و بازنشانی قابل تنظیم‌اند؛ مقدارهای خودکار و breakpoint زمان ساخت توضیح و مسیر تنظیم مناسب دارند. علامت «؟» کنار توکن‌های تب استایل، کارت همان متغیر را باز می‌کند.

در درباره‌ما، میان‌برهای «تصویر و برش»، «قاب و ارتفاع» و «عرض و جایگاه» تنظیمات این بخش را جدا می‌کنند. مسیر تصویر یا URL، جای برش با دو درصد، اندازه و فاصله‌ها برای هر دستگاه و بازه قابل ذخیره‌اند. گروه «محصولات منتخب» هم فقط شش کارت گرید بالای محصولات را ویرایش می‌کند.

ثبت محلی، فایل‌های واقعی را می‌نویسد. نسخهٔ GitHub Pages امکان نوشتن سورس ندارد و ZIP قابل جایگزینی می‌دهد. برای انتشارِ تغییرات ثبت‌شده باید Build و Push انجام شود.

راهنمای عملی: [CUSTOMIZER.md](CUSTOMIZER.md). قرارداد کلاس‌ها و ترتیب CSS: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). راهنمای Backend: [docs/backend-handoff.html](docs/backend-handoff.html).

نام و کاربرد متغیرهای استایل: [docs/DESIGN-TOKENS.md](docs/DESIGN-TOKENS.md). ZIP را با پوشه‌های تصاویر قبلی Merge کن؛ تغییرات مستقیم کاستومایزر همچنان باید ثبت و سپس منتشر شوند.

## ساخت و کنترل

```bash
npm run format:check
npm run check
npm run check:assets
npm run build
npm run build:pages
npm run preview:pages
```

`check:assets` را در نسخهٔ دارای تصاویر کامل اجرا کن. خروجی Build در `dist` قرار می‌گیرد؛ آن را داخل سورس نگه ندار.

- موبایل: تا 639px؛ تبلت: 640–1179px؛ دسکتاپ: از 1180px.
- فرمت کد با `npm run format` یکسان می‌شود. JSON پترن‌ها و CSS تولیدی از فرمت دستی مستثنی‌اند.
- `assets` ریشه و `public/assets` پشتیبانی می‌شوند؛ فایل هم‌نام در `public/assets` اولویت دارد.
- Auth واقعی و ثبت فرم‌ها هنوز به Backend نیاز دارند. adapterهای رویداد و قرارداد API حفظ شده‌اند.
- ۱۱۴ لینک placeholder موجود در قالب‌های رندرشده، همان محتوای قبلی‌اند و مقصد واقعی‌شان باید هنگام اتصال CMS تکمیل شود.
