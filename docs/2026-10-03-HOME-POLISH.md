## اعتبارسنجی

بررسی روی خروجی واقعی `npm run build:pages` در Chromium، با فونت‌ها و تصاویر موجود ریپو انجام شد.

| بررسی | نتیجه |
| --- | --- |
| `npm run check` | پاس؛ ۱۲ صفحه، importها، includeها، شناسه‌ها و لینک‌های داخلی |
| `npm run build:pages` | پاس |
| صفحه اصلی در 320، 375، 560، 639، 640، 768، 1024، 1179، 1180، 1440، 1920px | ۱۱ حالت؛ بدون خطای runtime، تصویر خراب یا سرریز متن |
| اندازه متن اصلی، کارت‌ها و لینک‌های صفحه اصلی | حداقل 14px؛ متن حقوقی فوتر 12px |
| هدر/فوتر ۱۲ صفحه در 375، 768، 1180، 1440px | ۴۸ حالت پاس؛ بدون سرریز فوتر یا تصویر خراب فوتر |
| CTA محصولات | هر دو لینک در یک ردیف در تمام ۱۱ عرض |
| تصاویر محصول | ابعاد تصویر و قاب برابر؛ `cover` و padding صفر |
| مقالات موبایل | حداکثر دو خط؛ متن کامل بدون تغییر باقی می‌ماند |
| hover و کیبورد | خط CTA با hover/focus؛ لینک‌های مشاهده همه بدون خط |
| منوی موبایل | زیرمنو، Escape و بسته‌شدن هنگام تغییر عرض به 1180px پاس |
| ورود/ثبت‌نام | باز و بسته‌شدن پنجره پاس |
| لینک «چرا مارپیچ» | انتقال به `about.html` پاس |
| مسیر خط منو در خروجی Pages | مسیر `/marpich-sanat/assets/icons/ui/nav-active-line.svg` درست است |

فایل PDF دیتاشیت قبلی هنوز در ریپو وجود ندارد؛ `check:assets` وجود 169 مورد از 170 دارایی مرجع را تأیید می‌کند و همین مورد را گزارش می‌دهد:


لینک‌های محتوایی تعیین‌نشده و اتصال فرم‌ها به بک‌اند مطابق نسخه فعلی پروژه باقی‌اند. بازبینی سایر صفحات شامل هدر و فوتر مشترک است؛ محتوای داخلی تمام صفحات دوباره طراحی نشده است.

## جایگزینی و انتشار

فایل ZIP یک بسته اصلاحات برای همین سورس است. محتویات آن را داخل ریشه پروژه، کنار `package.json`، کپی کنید و فایل‌های هم‌نام را Replace کنید. پوشه پروژه را حذف نکنید؛ فایل‌های تصاویر و فونت موجود لازم‌اند.

```bash
npm run check
npm run build:pages
git add .
git commit -m "Polish home page, footer and responsive cards"
git push origin main
```

پس از موفق‌شدن workflow GitHub Actions، صفحه آنلاین را با `Ctrl+F5` تازه کنید.
