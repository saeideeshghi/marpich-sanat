# راهنمای تغییر اندازه‌های فونت، هیرو و کارت‌ها

برای تغییر فونت‌ها و فاصله متن‌ها، فایل `src/css/type-settings.css` را باز کنید. بالای فایل مقادیر مشترک همه صفحات قرار دارد و بخش `PAGE OVERRIDES` برای تغییر اختصاصی هر صفحه است. ارتفاع‌ها در فایل جداگانه `src/css/hero-heights.css` با ID هیروی هر صفحه تنظیم می‌شوند. هر دو فایل از `src/css/responsive.css` وارد می‌شوند؛ قواعد نمایش در `src/css/components/hero.css` و `src/css/components/card-type.css` از این متغیرها استفاده می‌کنند.

## اندازه‌های پیش‌فرض

| بخش | دسکتاپ، از ۱۱۸۰ پیکسل | تبلت، ۶۴۰ تا ۱۱۷۹ پیکسل | موبایل، تا ۶۳۹ پیکسل |
| --- | --- | --- | --- |
| عنوان اول / مسیر صفحه | 28px | 20px | 20px |
| عنوان اصلی | 42px | 38px | 25px |
| متن توضیحی هیرو؛ مقدار دستی فعلی گیت‌هاب | 22px | 18px | 18px |
| حداقل ارتفاع هیرو؛ به‌جز Index | 31rem | 31rem | 25svh |
| حداقل ارتفاع هیروی Index؛ مقدار دستی فعلی | 44rem | 44rem | 44rem |
| متن معمولی خارج از کارت‌ها | 16px | 16px | 15px |
| عنوان کارت‌ها | 17px | 17px | 20px |
| توضیح کارت‌ها؛ حداکثر دو خط | 14px | 14px | 18px |
| CTA کارت‌ها | 12px | اندازه قبلی هر صفحه | اندازه قبلی هر صفحه |
| تگ‌ها و مشخصات کوتاه کارت‌ها | اندازه قبلی هر صفحه | اندازه قبلی هر صفحه | 10px |
| عنوان بخش‌های مشترک | 28px | 26px | 22px |

فونت کنترل‌های فرم `16px` و منوی ناوبری `14px` است. صفحات محصولات، صنایع، تهویه و جزئیات محصول پاراگراف توضیحی هیرو ندارند؛ برای آن‌ها متن جدیدی اضافه نشده است.

ارتفاع‌ها **حداقل** هستند. مقدار پایه صفحات داخلی همان `31rem` دسکتاپ/تبلت و `25svh` موبایل است؛ برای Index هر سه مقدار طبق تغییر دستی آخرین `main` برابر `44rem` قرار گرفته‌اند. هرجا متن بلند، فرم جست‌وجو یا کارت‌های تماس جا نشوند، هیرو به اندازه محتوایش بزرگ می‌شود. متن بریده نمی‌شود و اسکرول داخلی ندارد.

## تغییر ارتفاع هر صفحه با ID

در `src/css/hero-heights.css` برای هر یک از ۱۲ صفحه یک بلوک آماده وجود دارد. فقط مقادیر داخل بلوک صفحه موردنظر را تغییر دهید. مثلاً:

```css
/* projects.html */
#hero-projects {
    --hero-height-desktop: 31rem;
    --hero-height-tablet: 31rem;
    --hero-height-mobile: 25svh;
}
```

تغییر این بلوک فقط ارتفاع هیروی پروژه‌ها را تغییر می‌دهد. برای نمونه `36rem` در خط اول، حداقل ارتفاع دسکتاپ پروژه‌ها را عوض می‌کند؛ تبلت و موبایل همان مقدار خود را نگه می‌دارند. در بلوک `#hero-index` فعلاً هر سه مقدار `44rem` است؛ برای تغییر جداگانه موبایل یا تبلت همان خط مربوط را ویرایش کنید.

قواعد انتهای این فایل متغیر مناسب هر عرض را **روی خود هیرو** انتخاب می‌کنند؛ آن بخش را برای تنظیم معمول ارتفاع تغییر ندهید. متغیرهای ارتفاع را در `body[data-page]` یا `type-settings.css` قرار ندهید؛ محل اصلی آن‌ها بلوک ID هیرو است.

## تغییر مشترک فونت همه صفحات

مقادیر دارای پسوند `-desktop`، `-tablet` و `-mobile` ورودی‌های قابل ویرایش هستند. مثلاً برای تغییر عنوان اصلی همه صفحات، این سه خط را در بالای فایل تغییر دهید:

```css
--hero-title-desktop: 42px;
--hero-title-tablet: 38px;
--hero-title-mobile: 25px;
```

بخش انتهای فایل فقط انتخاب مقدار مناسب هر عرض صفحه را انجام می‌دهد؛ برای تغییر معمول سایزها، آن بخش را ویرایش نکنید.

## تغییر فونت مخصوص یک صفحه

در بخش `PAGE OVERRIDES`، پیش از قواعد انتخاب اندازه در انتهای فایل، برای صفحه موردنظر مقدار اختصاصی بنویسید. مثال زیر فقط عنوان دسکتاپ صفحه پروژه‌ها را تغییر می‌دهد:

```css
body[data-page="projects"] {
    --hero-title-desktop: 44px;
    --hero-title-tablet: 38px;
    --hero-title-mobile: 25px;
}
```

برای صفحه‌ای که از قبل در این بخش تنظیم دارد، مقدار جدید را داخل همان بلوک اضافه کنید. مثلاً در بلوک `about` می‌توانید فونت متن توضیحی را اضافه کنید و تنظیم فاصله پایین و عکس تیم را نگه دارید:

```css
body[data-page="about"] {
    --hero-bottom: 64px;
    --hero-summary-desktop: 36px;
    --hero-summary-tablet: 36px;
    --hero-summary-mobile: 24px;
    --hero-description-desktop: 22px;
    --hero-description-tablet: 18px;
    --hero-description-mobile: 18px;
}
```

| فایل صفحه | `data-page` برای فونت‌ها | ID هیرو برای ارتفاع |
| --- | --- | --- |
| `index.html` | `home` | `hero-index` |
| `projects.html` | `projects` | `hero-projects` |
| `project-details.html` | `project-details` | `hero-project-details` |
| `products.html` | `products` | `hero-products` |
| `product-details.html` | `product-details` | `hero-product-details` |
| `industries.html` | `industries` | `hero-industries` |
| `industry-textile.html` | `industry-textile` | `hero-industry-textile` |
| `air-handling.html` | `air-handling` | `hero-air-handling` |
| `expertise.html` | `expertise` | `hero-expertise` |
| `articles.html` | `articles` | `hero-articles` |
| `about.html` | `about` | `hero-about` |
| `contact.html` | `contact` | `hero-contact` |

## فاصله‌ها و فونت بخش‌های دیگر

- `--home-hero-content-margin-top`: فاصله اضافه بالای محتوای هیروی Index؛ مقدار دستی فعلی `105px` در بلوک `body[data-page="home"]` حفظ شده است. این مقدار مستقل از padding بالای هیرو است.
- `--hero-top-desktop/tablet/mobile`: فاصله بالای محتوای هیرو؛ باید برای لوگو و هدر جا بگذارد.
- `--hero-bottom`: فاصله پایین محتوای هیرو.
- `--hero-eyebrow-leading`، `--hero-title-leading` و `--hero-description-leading`: نسبت فاصله بین خطوط.
- `--text-body-desktop/tablet/mobile`: متن‌های معمولی مشترک.
- `--text-card-desktop/tablet/mobile`: عنوان‌های کوچک قدیمی خارج از نقش‌های کارت؛ برای کارت‌ها از `--card-title-*` استفاده کنید.
- `--text-section-desktop/tablet/mobile`: عنوان بخش‌های مشترک.
- `--text-control` و `--text-navigation`: کنترل‌های فرم و منوی ناوبری.
- `--hero-summary-desktop/tablet/mobile`: میزان هم‌پوشانی ترجیحی عکس یا کارت بعد از هیرو در درباره ما، جزئیات پروژه، جزئیات محصول و صنعت نساجی.

ماژول `src/js/components/hero.js` میزان هم‌پوشانی را با فضای خالی زیر آخرین خط هیرو تطبیق می‌دهد و حداقل ۲۴ پیکسل فاصله با متن نگه می‌دارد. بنابراین تغییر فونت یا شکستن خطوط، عکس یا کارت را روی متن نمی‌اندازد. مقدار محاسبه‌شده `--hero-summary-overlap` را مستقیم ویرایش نکنید.

## تنظیم کارت‌ها

قواعد کارت‌ها از هیرو و عنوان بخش‌ها مستقل‌اند. برای همه کارت‌ها این مقدارها را در بالای `type-settings.css` تغییر دهید:

```css
--card-title-desktop: 17px;
--card-title-tablet: 17px;
--card-title-mobile: 20px;
--card-description-desktop: 14px;
--card-description-tablet: 14px;
--card-description-mobile: 18px;
--card-cta-desktop: 12px;
--card-tag-mobile: 10px;
--card-description-lines: 2;
```

برای تغییر مخصوص صفحه، در `PAGE OVERRIDES` همین متغیرها را داخل بلوک `data-page` بنویسید. مثال:

```css
body[data-page="projects"] {
    --card-title-mobile: 20px;
    --card-description-mobile: 18px;
    --card-description-lines: 2;
}
```

ریشه کارت کلاس `site-card` دارد و بخش‌های آن با این نقش‌ها مشخص شده‌اند:

| نقش | کلاس |
| --- | --- |
| عنوان | `site-card__title` |
| توضیح | `site-card__description` |
| CTA | `site-card__cta` |
| متن CTA، بدون آیکن و فلش | `site-card__cta-label` |
| تگ یا مشخصات کوتاه | `site-card__tag` |

کارت‌های محصولات، پروژه‌ها، مقالات، صنایع منتخب، حوزه‌های تخصصی، گواهینامه‌ها، دستاوردها، مزایا، دفاتر تماس و نظرات مشتریان از همین نقش‌ها استفاده می‌کنند. کارت معرفی محصول در جزئیات محصول و ردیف مقاله‌های صفحه اصلی هم پوشش داده شده‌اند. فرم‌ها و جدول‌های فنی ساختار و متن کامل خود را دارند.

توضیح‌ها justify هستند و خط آخر راست‌چین است. متن بلند با `line-clamp` پس از دو خط سه‌نقطه می‌گیرد؛ متن کوتاه به‌صورت طبیعی یک خط یا دو خط است. متن اصلی از HTML حذف نمی‌شود. ارتفاع ثابت برای پاراگراف قرار نگرفته تا متن کوتاه فضای خالی اضافه نسازد.

خط CTA در حالت معمول پنهان است. روی دستگاه دارای hover، با رفتن نشانگر روی کارت و با فوکوس صفحه‌کلید روی CTA ظاهر می‌شود. فقط متن خط می‌گیرد؛ فلش و آیکن خط نمی‌گیرند. روی دستگاه لمسی خط hover فعال نمی‌شود. اندازه فعلی CTA موبایل/تبلت و تگ دسکتاپ/تبلت دست‌نخورده مانده‌اند؛ در کارت دفتر تماس، CTA موبایل همچنان `13px` است.

برای اضافه‌کردن کارت جدید، این کلاس‌ها را در HTML یا template آن قرار دهید. تگ‌های مشخصات محصولات هنگام render نیز کلاس `site-card__tag` دریافت می‌کنند. CSS فونت کارت را دوباره در فایل اختصاصی صفحه ننویسید.

## ساختار هیرو و هدر

ریشه هیرو `data-site-hero`، کلاس `site-hero` و ID مستقل جدول بالا را دارد. محتوا، عنوان اول، عنوان اصلی و توضیح با کلاس‌های `site-hero__content`، `site-hero__eyebrow`، `site-hero__title` و `site-hero__description` مشخص شده‌اند. سایزهای عددی قبلی Tailwind از همین عناصر حذف شده‌اند تا چند قانون هم‌زمان فونت را تغییر ندهند.

هدر مشترک مستقیماً زیر `body` قرار دارد تا دراپ‌داون‌ها بالای سایر بخش‌ها نمایش داده شوند. پترن هدر همچنان داخل ریشه هیرو قرار می‌گیرد؛ include هدر را دوباره داخل هیرو منتقل نکنید.

عکس تیم درباره ما با `width: 100%`، `height: auto` و بدون `max-height` نمایش داده می‌شود. نسبت اصلی عکس حفظ است و صفحه برای دیدن کامل عکس بزرگ اسکرول می‌خورد. تنظیم ارتفاع هیرو با ID، ارتفاع عکس را محدود نمی‌کند؛ هم‌پوشانی آن با هیرو همچنان فاصله امن از متن را رعایت می‌کند.

دراپ‌داون‌های فرم جست‌وجوی محصولات، صنایع و تهویه قابل تایپ‌اند. جست‌وجو فقط گزینه‌های همان فیلد را فیلتر می‌کند؛ تا انتخاب گزینه با کلیک یا Enter، مقدار `<select>` اصلی و داده ارسالی فرم عوض نمی‌شود. حروف فارسی/عربی «ی» و «ک» معادل در نظر گرفته می‌شوند. قرارداد `catalog:search` و اتصال آینده به بک‌اند حفظ شده است.

پس از تغییر اندازه‌ها، صفحه موردنظر را در عرض‌های ۳۹۰، ۹۰۰ و ۱۴۴۰ پیکسل ببینید و این دو دستور را اجرا کنید:

```bash
npm run check
npm run build:pages
```
