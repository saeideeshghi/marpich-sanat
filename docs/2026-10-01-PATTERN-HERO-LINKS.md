# اصلاح پترن، ارتفاع عکس و underline — ۱ اکتبر ۲۰۲۶، بازبینی دوم

## رفتار نهایی

- هدر و فوتر از زمان‌بندی مشترک استفاده می‌کنند. ورود لایه فوتر به دید، انیمیشن آن را از صفر شروع نمی‌کند؛ زمان موج و نور از یک ساعت مشترک به دست می‌آید. فقط لایه قابل مشاهده رندر می‌شود و reduced-motion رعایت می‌شود. geometry، gradient، رنگ‌ها، سرعت تعریف‌شده در تنظیمات و طرح فوتر عوض نشده‌اند.
- بوم SVG همان ارتفاع صادراتی ۴۰۴px موبایل و ۴۳۰px دسکتاپ را دارد. قاب بیرونی هدر به زمینه تیره همان صفحه محدود می‌شود؛ در درباره‌ما ارتفاع خود hero و در تماس و مقالات ارتفاع زمینه intro معیار crop است. بنابراین پترن به سطح روشن پایین هدر نشت نمی‌کند و تغییر ارتفاع محتوا هندسه SVG را نمی‌کشد.
- زمینه تیره مقالات با ارتفاع واقعی عنوان و توضیح تطبیق پیدا می‌کند. در عرض باریک، متن چندخطی سفید از زمینه تیره بیرون نمی‌زند. پس از تغییر عرض یا بارگذاری فونت هم اندازه دوباره محاسبه می‌شود.
- تصویر هیروی خانه بر اساس ارتفاع قاب اندازه می‌گیرد: `height: 100%` و `width: auto` با حفظ نسبت طبیعی تصویر. محدود کردن عکس به عرض صفحه دیگر ارتفاع آن را در موبایل کوچک نمی‌کند. بزرگ‌نمایی ۱۱۵٪ حذف شده است؛ عرض اضافی داخل hero بریده می‌شود.
- عکس درباره‌ما عرض و ارتفاع طبیعی دارد و هم‌زمان به عرض محتوا و فضای موجود دید اول محدود می‌شود. اندازه‌گیری نسبت به سند است؛ اسکرول باعث کوچک و بزرگ شدن عکس نمی‌شود. در صفحه‌های بسیار کم‌ارتفاع، اسکرول طبیعی به کوچک شدن بیش از حد عکس ترجیح داده می‌شود.
- underline تنها روی متن لینک قرار می‌گیرد. لینک والد و فلش یا آیکن کنارش خط ندارند. کلاس `site-text-link` برای لینک و `site-text-link__label` برای متن، قرارداد مشترک این رفتار هستند. خطوط border قبلی روی متن خنثی شده‌اند.
- لینک‌های کارت‌ها و «مشاهده همه» در حوزه‌های تخصصی و پروژه‌های شاخص خانه، و لینک‌های «مطالعه بیشتر» و CTA صفحه حوزه‌های تخصصی با همین قرارداد اصلاح شده‌اند. لینک کارت‌های محصولات، صنایع، پروژه‌ها، درباره‌ما و مقالات نیز همین رفتار را دارند.

## بررسی

- `npm run check` و `npm run build` موفق بودند.
- ۱۲ صفحه در ۱۱ عرض از ۳۲۰ تا ۲۵۶۰px: ۱۳۲ حالت. اسکن متن قابل مشاهده بیرون‌زدگی افقی صفحه یا فشردگی افقی کلمات را نشان نداد. جدول‌ها و نوارهای دارای پیمایش داخلی مجاز از این سنجش مستثنا هستند.
- این بار انیمیشن با reduced-motion خاموش بررسی شد: موج و نور متحرک در ۴۶ لایه قابل مشاهده، شامل تمام هدرها و فوترها در موبایل و دسکتاپ، جلو رفتند. هم‌زمانی دو لایه و حالت reduced-motion جداگانه پاس شدند.
- زمینه تیره مقالات در تمام ۱۱ عرض، کل متن heading را پوشش داد. قاب پترن درباره‌ما، تماس و مقالات از محدوده تیره بیرون نرفت؛ بوم و هندسه گرافیک مشترک حفظ شدند.
- underline متن، نبود decoration روی والد/آیکن و نبود border زیر label روی لینک‌های علامت‌گذاری‌شده در همه صفحات بررسی شد.
- عکس آزمایشی ۱۳۱۱×۵۰۰ در شش viewport برای خانه و درباره‌ما استفاده شد: نسبت تصویر حفظ شد، عکس خانه ارتفاع hero را پر کرد و عکس درباره‌ما کامل داخل دید اول بود. این fixture داخل خروجی نیست.
- آزمون قبلی CTA، منوی فعال آبی، مشتریان بدون scrollbar/کنترل و انتخاب SVG صحیح دوباره پاس شد. خطای JavaScript در تعامل‌های آزموده‌شده ثبت نشد.
- partial فوتر، هر دو JSON تنظیمات artwork و دو SVG همکاری نسبت به تحویل قبلی عیناً حفظ شدند. تغییر پترن در renderer و قاب نمایش آن است.

گزارش خام: `responsive-2026-10-01b.json` و `interactions-2026-10-01b.json`.

## اجرا و محدودیت

تصاویر، لوگوها و فونت‌های اصلی همراه ZIP ورودی نبودند. آزمون‌های مرورگر با فونت جایگزین انجام شدند؛ اندازه عکس با fixture بررسی شد. فاصله‌گذاری دقیق با Peyda و ظاهر واقعی عکس‌ها نیاز به بازبینی روی نسخه دارای دارایی‌های اصلی دارد. این بررسی شامل تمام مرورگرها یا تمام ارتفاع‌های ممکن نیست.

سورس را با پروژه خود ادغام کنید و پوشه‌های تصاویر و فونت‌های موجود را حفظ کنید. دو SVG موجود در `public/assets/icons/process` را هم منتقل کنید. پوشه دارایی‌های کامل خود را با پوشه کم‌حجم این بسته جایگزین نکنید.

```bash
npm ci
npm run check
npm run dev
npm run build
```

`dist` و `node_modules` داخل ZIP نیستند. اگر خروجی build قبلی را نمایش می‌دهید، build جدید را جایگزین کنید و مرورگر را با Ctrl+F5 تازه کنید.
