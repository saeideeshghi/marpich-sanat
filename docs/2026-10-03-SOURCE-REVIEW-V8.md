سورس مستقیماً از آخرین `main` دریافت شد:

```text
505f425e56cdced292d213b2da05f7913281a2f0
```

[commit مبنا](https://github.com/saeideeshghi/marpich-sanat/commit/505f425e56cdced292d213b2da05f7913281a2f0) و آخرین اجرای GitHub Actions آن هنگام بررسی موفق بودند. تغییرات این بسته محلی‌اند و با تحویل ZIP خودکار روی GitHub نوشته نشده‌اند.

## تغییرات سورس

- HTMLهای صفحات، templateها، CSSها، JavaScript و JSONهای سورس با یک قالب ثابت مرتب شدند. ترتیب import، selector، declaration و کلاس‌های Tailwind حفظ شد. در مرحله قالب‌بندی، AST جاوااسکریپت و ساختار قواعد CSS و داده JSON قبل و بعد مقایسه شدند.
- تنظیمات formatter و editor با indentation چهار فاصله برای HTML/CSS/JS و دو فاصله برای JSON هماهنگ‌اند. حساسیت whitespace در HTML برابر `strict` است. dependency جدید اضافه نشده و lockfile تغییر نکرده است.
- `build/public-asset-base.js` حالا `data-fallback` را هم در خروجی Pages به مسیر پروژه تبدیل می‌کند. قبلاً تصویر جایگزین ممکن بود به `/assets/...` در ریشه دامنه درخواست شود. مسیرهای `src`، `srcset` و `data-image-candidates` نیز بدون پیشوند تکراری حفظ‌اند.
- تطبیق جست‌وجوی فارسی/عربی در `src/js/utils/search-text.js` مشترک شده است. جست‌وجوی مقالات نیز «ی/ي»، «ک/ك»، اعراب، فاصله/نیم‌فاصله و شکل‌های فارسی/عربی اعداد را تطبیق می‌دهد. متن نمایشی و مقدار native فیلدها دست‌نخورده‌اند.
- وضعیت انتخاب دسته‌بندی مقالات علاوه بر کلاس فعال با `aria-pressed` اعلام می‌شود. تغییر دسته و بازنشانی از یک تابع مشترک استفاده می‌کنند.
- Reset هر کدام از فرم‌های مشاوره، مقادیر native پیش‌فرض را بعد از اجرای Reset به فرم دیگر انتقال می‌دهد؛ تغییر عرض صفحه دیگر داده پاک‌شده را از فرم مخفی برنمی‌گرداند. checkbox/radio بر اساس `checked` همگام می‌شوند و file input کپی نمی‌شود.
- Reset فرم RFQ برچسب فایل انتخاب‌شده را هم به حالت اولیه برمی‌گرداند. محدودیت فرمت و ۲۰ MiB، drag/drop، FormData و قرارداد cancelable حفظ شده‌اند.
- مقداردهی چیدمان هیرو در فراخوانی دوباره رفتار مشترک، observer تکراری ایجاد نمی‌کند.
- بررسی ساختاری وجود یک ریشه هیرو با ID درست هر صفحه را کنترل می‌کند. بررسی قراردادها، مسیر fallback در Pages و تطبیق متن فارسی/عربی را نیز پوشش می‌دهد.
- `check:assets` فقط سورس واقعی سایت و HTMLهای renderشده را بررسی می‌کند؛ آدرس آزمایشی تست‌ها و مسیرهای قدیمی manifestها به‌عنوان دارایی واقعی گزارش نمی‌شوند. manifest دارایی‌ها دوباره از سورس فعلی ساخته شده است.

## حفظ تغییرات دستی

- Index در هر سه حالت حداقل `44rem` دارد؛ به مقدار `41rem` نسخه پیشین برگردانده نشده است.
- فاصله اضافه بالای محتوای هیروی Index همان `105px` است و با متغیر `--home-hero-content-margin-top` در بلوک `home` فایل `type-settings.css` تنظیم می‌شود.
- فونت توضیح هیرو `22/18/18px`، سایر فونت‌های هیرو، تایپوگرافی کارت‌های نسخه ۶، خط CTA در hover، ارتفاع صفحات داخلی و عکس کامل درباره ما حفظ‌اند.
- ظاهر فعلی هدر، فوتر، منوها، پترن و کانتینرهای صفحات حفظ شده است. dependencyها، قراردادهای سرور و workflow انتشار همان نسخه مبنا هستند.
- [راهنمای اندازه‌ها](TYPE-SETTINGS.md) با مقادیر دستی فعلی به‌روز شده و [نقشه سورس](CODE-MAP.md) محل تغییر هر بخش را مشخص می‌کند.

## نتیجه بررسی

- `npm run check` موفق.
- `npm run build` برای مسیر محلی و `npm run build:pages` برای Pages موفق.
- بررسی formatter و `git diff --check` موفق.
- ۱۲ صفحه در عرض‌های ۳۲۰، ۳۹۰، ۶۳۹، ۶۴۰، ۹۰۰، ۱۱۷۹، ۱۱۸۰، ۱۴۴۰ و ۱۹۲۰ بررسی شدند. در **۱۰۸ چیدمان**، اندازه و موقعیت عناصر و استایل‌های محاسبه‌شده با baseline آخرین `main` برابرند؛ سرریز افقی و تصویر خراب مشاهده نشد.
- دراپ‌داون‌های ۱۲ فیلد در سه عرض، تطبیق متن مقالات، Reset فرم‌های responsive، فایل RFQ، مسیر fallback با خطای تصویر شبیه‌سازی‌شده، grid/list و انتقال منوی موبایل به dialog بررسی شدند.
- بررسی‌های رفتاری نسخه قبلی نیز شامل همه منوهای دسکتاپ، تصاویر مقالات در grid/list، لوگوی hover پروژه‌ها، زوم صنعت و منوی موبایل موفق بودند.
- گزارش ماشینی خلاصه: [source-review-v8.json](source-review-v8.json).

## فایل‌های باقی‌مانده و تحویل

بسته **سورس کامل** است و فایل‌های دست‌خورده و دست‌نخورده موردنیاز توسعه را دارد. پوشه‌های `assets`، `public/assets`، `fonts`، `public/fonts`، عکس‌های پیش‌نمایش مستندات، `node_modules`، `dist`، `.cache` و `.git` در ZIP نیستند. assets و fonts موجود در سیستم خودتان را حفظ کنید. لینک عکس در گزارش‌های تاریخی فقط وقتی فایل‌های قبلی موجود باشند باز می‌شود.

بررسی دارایی‌های واقعی در ریپو **۱۷۰ از ۱۷۱** فایل را پیدا کرد؛ فقط دیتاشیت اصلی زیر در ریپو نبود:

```text
public/assets/documents/product-details/northair-pro-flow-datasheet.pdf
```

فایل واقعی را اگر در سیستم محلی دارید با همین مسیر نگه دارید یا اضافه کنید. PDF جایگزین ساختگی و تغییر مسیر دانلود اضافه نشده است. فرم‌ها و Auth همچنان به اتصال بک‌اند/CMS نیاز دارند؛ ۱۱۶ لینک placeholder موجود نیز باید هنگام اتصال محتوا تعیین شوند.

فهرست و hash فایل‌های همین بسته در `final-source-v8-manifest.json` است. manifestها و گزارش‌های نسخه‌های قبلی سابقه هستند و معیار اعتبارسنجی نسخه ۸ محسوب نمی‌شوند. روش نصب در [APPLY-PAGES-FIXES.txt](../APPLY-PAGES-FIXES.txt) آمده است.
