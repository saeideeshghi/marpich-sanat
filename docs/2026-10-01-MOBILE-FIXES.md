# اصلاح موبایل، پترن و فرایند همکاری — ۱ اکتبر ۲۰۲۶

## تغییرات جاری

- منوی موبایل: مقصد فعال آبی `#79B6ED` است. صفحه‌های زیرمجموعه، دکمه گروه مربوط به خود را هم فعال می‌کنند؛ `aria-current` روی لینک یا دکمه مناسب قرار می‌گیرد.
- پترن هدر: همه صفحه‌های داخلی از هندسه مشترک `site-pattern.json` و بوم ثابت استفاده می‌کنند. ارتفاع بوم ۴۰۴px در عرض کمتر از ۶۴۰px و ۴۳۰px در عرض‌های دیگر است؛ ارتفاع خاص صفحه تماس یا درباره‌ما پترن را کش نمی‌آورد. هندسه، رنگ‌ها و حرکت خطوط عوض نشده‌اند.
- فوتر تأییدشده و فایل تنظیمات آن نسبت به تحویل قبلی دقیقاً یکسان مانده‌اند. breakpoint پترن فوتر همان ۴۶۳px صادراتی است؛ اصلاح breakpoint هدر روی فوتر اثر ندارد.
- هیروی خانه: تصویر از بزرگ‌نمایی ۱۱۵٪ خارج شده و با `object-fit: contain` داخل قاب قرار می‌گیرد. CTAها به جای جای‌گذاری مطلق متن و آیکن، با flex چیده می‌شوند؛ عرض متن و فاصله آیکن برای موبایل اصلاح شده‌اند.
- مشتریان: نوار خودکار پیوسته، بدون scrollbar و دکمه قبلی/بعدی/پخش/توقف. دو گروه یکسان یک حلقه تصویری می‌سازند؛ گروه تکراری از screen reader پنهان است. در موبایل دو، عرض میانی سه، دسکتاپ چهار و نمایشگر بزرگ پنج لوگو هدف نمایش هستند.
- نوار مشتریان خارج از دید یا در تب مخفی متوقف می‌شود؛ hover فقط روی دستگاه دارای hover آن را متوقف می‌کند. برای reduced-motion، همه لوگوها در فهرست ثابت نمایش داده می‌شوند. افزودن مشتری با گسترش `partners.logos` در `src/data/pages/home.json` انجام می‌شود.
- فرایند همکاری: چهار مرحله افقی مطابق ساختار رفرنس موبایل/دسکتاپ، با متن توضیحی در دسکتاپ و عنوان در موبایل. دو SVG ارسال‌شده بدون دست‌کاری زیر `public/assets/icons/process/connector-desktop.svg` و `connector-mobile.svg` قرار گرفته‌اند. انتخاب نسخه با `<picture>` در ۶۴۰px انجام می‌شود.
- لینک‌های متنی دارای `text-decoration` اکنون underline واقعی دارند؛ خطوط تقلیدی بعضی لینک‌ها حذف شده‌اند. reset عمومی لینک‌ها و ظاهر کنترل‌های ناوبری حفظ شده‌اند.
- چیدمان کارت‌ها، برچسب مشخصات، اطلاعات شعب، فونت‌ها و فاصله‌های موبایل به تفکیک اجزا اصلاح شده‌اند. ورودی فرم‌ها ۱۶px باقی می‌مانند. نمایشگرهای بزرگ از محدوده محتوای تا ۱۶۸۰px استفاده می‌کنند.

## بررسی انجام‌شده

۱۲ صفحه در عرض‌های ۳۲۰، ۳۶۰، ۳۹۰، ۴۳۰، ۶۴۰، ۷۶۸، ۱۰۲۴، ۱۱۸۰، ۱۴۴۰، ۱۹۲۰ و ۲۵۶۰px در Chromium بررسی شدند: ۱۳۲ حالت.

اسکن متن‌های قابل مشاهده، خروج افقی صفحه یا فشردگی افقی کلمات داخل عناصر را نشان نداد. محتوای خارج قاب نوار مشتریان و اسکرول‌های داخلی مجاز از سنجش خروج از viewport مستثنا هستند. برچسب‌های چهارمرحله‌ای موبایل ۱۰٫۵px هستند؛ فلش‌های تزئینیِ بدون متن از معیار اندازه فونت کنار گذاشته می‌شوند. این آزمون به معنی پوشش تمام ارتفاع‌ها، مرورگرها، فونت‌ها یا تمام حالت‌های تعاملی نیست.

آزمون هدفمند تأیید کرد: مقصد فعال آبی در هر ۱۲ منوی موبایل؛ خروج از منو با Escape؛ قرارگیری متن CTA داخل دکمه و عدم برخورد با آیکن در هفت عرض؛ تناسب قاب عکس هیرو؛ انتخاب SVG درست؛ نبود دکمه و scrollbar مشتریان؛ حرکت نوار روی viewport لمسی؛ حالت reduced-motion؛ یکسان بودن تنظیمات پترن درباره‌ما، تماس، محصولات و مقالات در سه عرض. خطای JavaScript در تعامل‌های آزموده‌شده ثبت نشد. حفظ breakpoint فوتر در ۵۰۰px نیز جداگانه بررسی شد.

`npm run check` و `npm run build` موفق بودند. گزارش خام در `responsive-2026-10-01.json` و `interactions-2026-10-01.json` است. مقایسه بایتی، حفظ partial فوتر و تنظیمات پترن فوتر و تطابق دو SVG با فایل‌های آپلودشده را تأیید کرد.

## نصب و محدودیت تصاویر

تصاویر، لوگوهای اصلی و فونت‌های Peyda در ZIP ورودی نبودند. بررسی مرورگر با فونت جایگزین و بدون این دارایی‌ها انجام شد؛ ظاهر واقعی تصویر هیرو، آیکن مراحل، لوگوها و فاصله دقیق متن با فونت اصلی به بازبینی روی پروژه کامل نیاز دارد. هیچ تصویر یا فونت آزمایشی در خروجی نیست.

سورس این بسته را با پروژه خود ادغام کنید و پوشه‌های تصاویر و فونت‌های اصلی خود را حفظ کنید. دو SVG جدید داخل `public/assets/icons/process` را هم منتقل کنید؛ پوشه `public/assets` موجود را با این پوشه کم‌حجم جایگزین نکنید. سپس `npm ci`، `npm run check` و `npm run build` را اجرا کنید. برای مشاهده توسعه `npm run dev` است. `node_modules` و `dist` داخل بسته نیستند.
