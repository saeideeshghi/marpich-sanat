# اصلاحات نسخه v2 — ۲ اکتبر ۲۰۲۶

این بسته برای جایگزینی فایل‌های اصلاح‌شده در Clone فعلی پروژه است؛ تصاویر و فونت‌های موجود را نگه دارید. مبنای تغییرات، branch `main` با commit `79622b9f2ba92dcb4f21e208b6b5b341011956c7` و سه تصویر مرجع این بازبینی است. نسخه اصلی پروژه و وابستگی‌های آن تغییر نکرده‌اند.

## جایگزینی روی سیستم

1. ZIP را بیرون از پوشه پروژه Extract کنید.
2. محتویات آن را در ریشه Clone فعلی کپی و Replace کنید؛ `src` و `public` را Merge کنید. هیچ پوشه‌ای را حذف نکنید.
3. پوشه `.git`، تصاویر `assets` و فونت‌های فعلی را نگه دارید. ZIP شامل `node_modules` و تصاویر تکراری سنگین نیست.
4. در همان ریشه پروژه، دستورهای زیر را اجرا کنید.

```bash
npm ci
npm run check
npm run build:pages
npm run preview:pages
```

Preview در `http://localhost:4173/marpich-sanat/index.html` باز می‌شود. فایل HTML سورس را مستقیم با file:// باز نکنید؛ includeها به Vite نیاز دارند.

بعد از بررسی:

```bash
git add .
git commit -m "Fix hero, footer and responsive layouts"
git push origin main
```

انتشار با workflow موجود GitHub Actions انجام می‌شود. این بسته مستقیماً روی GitHub منتشر نشده است. بعد از موفق‌شدن Actions، صفحه را با Ctrl+F5 تازه کنید.

## تغییرات ظاهری

- Hero: ارتفاع مشخص، عکس بدون فضای خالی پایین، گرادینت پیوسته، لوگوی SVG اصلی و موقعیت مناسب متن و CTA. جمله عنوان در تبلت به دو بخش معنایی شکسته می‌شود.
- Footer: یک HTML مشترک برای تمام اندازه‌ها؛ سه ستون دسکتاپ مطابق انتخاب مالک، دسته‌بندی‌های دو ستونه موبایل، تماس، شبکه‌های اجتماعی، ISO / CE / نماد اعتماد و متن «طراحی شده توسط تیم مارکتینگ شرق رایا».
- پترن Footer مستقل از Header است و مطابق جهت مرجع از بالا به پایین در کناره چپ حرکت می‌کند. هندسه Header تغییر نکرده است.
- خوانایی: پاراگراف‌های اصلی 15–16px، متن کارت و لینک‌ها حداقل 14px؛ کپشن حقوقی Footer اندازه جداگانه دارد. قوانین متناقض 10–12px موبایل حذف شده‌اند؛ متن فارسی با عرض طبیعی و راست‌چین نمایش داده می‌شود.
- صفحه اصلی: محصولات و پروژه‌ها در موبایل دو ستونه و زیر 360px تک‌ستونه‌اند؛ هر چهار کارت موجود نمایش داده می‌شوند. مراحل همکاری موبایل دو ردیف دارد.
- کنترل‌های فیلتر، Grid/List، ورودی‌ها و تماس فضای کافی برای کلیک دارند. فیلترها به‌جای کوچک‌شدن فونت Wrap می‌شوند.
- مسیر سه تصویر جایگزین Textile به فایل‌های PNG موجود اصلاح شد. مسیر پترن مفقود محصولات با خطوط ظریف CSS جایگزین شد.

| Grid/List پنج فهرست | محصولات، هواساز، صنایع، پروژه‌ها و مقالات در 375 / 768 / 1440px پاس شد |
| Custom Select کاتالوگ | بازشدن، انتخاب و Escape پاس شد |
| FAQ صنعت نساجی | باز و بسته‌شدن پاس شد |

## فایل محتوایی باقی‌مانده

این فایل در ریپو موجود نیست:

```text
public/assets/documents/product-details/northair-pro-flow-datasheet.pdf
```

برای فعال‌شدن دانلود دیتاشیت، PDF اصلی محصول را در همین مسیر اضافه کنید. `npm run check:assets` تا زمان اضافه‌شدن آن یک خطای مفقودبودن فایل گزارش می‌کند؛ Build و سایر چک‌ها پاس می‌شوند. فایل ساختگی جایگزین دیتاشیت نشده است.

فرم‌ها، احراز هویت و داده‌های کاتالوگ همچنان قرارداد فرانت‌اند نسخه قبلی را دارند و اتصال واقعی به بک‌اند در این بازبینی انجام نشده است. لینک‌های محتوایی تعیین‌نشده قبلی در README ثبت شده‌اند.
