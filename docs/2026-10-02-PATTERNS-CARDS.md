| فایل | مسئولیت |

| `src/css/components/pattern.css` | سطح نمایش و محو نرم پترن در انتهای هدر. |

## بررسی

- `npm run check`: هر سه بررسی پروژه، Componentها و Handoff پاس شدند.
- `npm run build:pages`: خروجی مخصوص GitHub Pages ساخته شد.
- بررسی مرورگر در ۱۲ صفحه و ۱۰ عرض: ۳۲۰، ۳۷۵، ۵۲۰، ۶۳۹، ۶۴۰، ۷۶۸، ۱۱۷۹، ۱۱۸۰، ۱۴۴۰ و ۱۹۲۰px.
- بعد از تنظیم هم‌ارتفاعی و باکس تماس، ۴۸ چیدمان در عرض‌های ۳۷۵، ۶۳۹، ۷۶۸ و ۱۴۴۰px دوباره بررسی شدند: متن کارت قطع‌شده، تصویر خراب، بیرون‌زدگی کارت و خطای JavaScript پیدا نشد؛ کارت‌های هر ردیف هم‌ارتفاع بودند.
- منوی موبایل هر ۱۲ صفحه، Grid/List پنج فهرست، تغییر پترن در مرزهای نمایشگر، تطابق هندسه هدر/فوتر دسکتاپ و حرکت و Reduced Motion سه صفحه مقالات/تماس/درباره بررسی شدند.
- فایل `.cmd` از نظر دستورها، مسیرها و توقف روی خطا بازبینی شده؛ محیط اجرای این بررسی Linux است و خود Push ویندوزی روی سیستم کاربر اجرا خواهد شد.

این بررسی با Chromium محلی انجام شده است؛ تصاویر Preview داخل `docs/previews/pass2` هستند. هیچ Commit یا Push از این محیط به ریپو انجام نشده است.

## انتشار هر آپدیت

در Windows، ترمینال VS Code را در ریشه همان پروژه باز کنید و اجرا کنید:

```powershell
.\PUSH-GITHUB.cmd
```

وقتی Actions سبز شد، سایت را با Ctrl + F5 باز کنید. روش دستی و رفع خطاها در `GITHUB-UPLOAD.md` آمده است. سایت از `main` منتشر می‌شود؛ Tag `v2.0.0` سابقه ثبت‌شده قبلی است.
