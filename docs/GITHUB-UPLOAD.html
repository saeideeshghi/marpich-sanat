آپلود نسخه نهایی مارپیچ صنعت

اصلاحات قبلی در این بسته حفظ شده‌اند. مسیر تصاویر قدیمی و build مخصوص GitHub Pages اصلاح شده و ۹ فونت اصلی Peyda همراه فایل هستند.

تصاویر و لوگوهای سنگین مطابق درخواستت داخل ZIP نیستند. فایل‌های موجود در Clone و assets اصلی روی سیستم خودت را نگه دار و قبل از Push ادغام کن. فهرست مسیرهای لازم در assets-manifest.json و ۱۵ مسیر غایب در ریپوی قدیمی و ZIP ارسالی در github-assets-missing.json است؛ ممکن است آن‌ها در assets محلی خودت موجود باشند.

۱. نسخه تازه از ریپو بگیر

در یک پوشه تازه PowerShell را باز کن. از همین ریپو استفاده می‌کنیم؛ لازم نیست ریپوی جدید بسازی یا ریپوی قبلی را حذف کنی.

git clone https://github.com/saeideeshghi/marpich-sanat.git marpich-sanat-new
cd marpich-sanat-new

۲. محتویات ZIP را کپی کن

ZIP نهایی را بیرون ریپو Extract کن و تمام محتویاتش را داخل marpich-sanat-new کپی و Replace کن. package.json باید در ریشه باشد. پوشه .git مربوط به Clone را نگه دار. پوشه assets و فونت‌های موجود را حذف نکن؛ فایل‌های public بسته را با آن‌ها ادغام کن. تصاویر تازه‌ای که روی سیستم خودت داری را با نام اصلی در public/assets اضافه کن. assets در ریشه نیز پشتیبانی می‌شود. خود ZIP، node_modules، dist و .cache را کپی نکن.

۳. فایل‌ها و سایت را بررسی کن

Node.js 22.12 یا بالاتر لازم است. دستورها را یکی‌یکی اجرا کن. check:assets مسیر هر فایل مفقود را نشان می‌دهد؛ آن را از assets اصلی خودت اضافه کن و دوباره بررسی کن. build موفق به معنی موجود بودن همه تصاویر نیست.

npm ci
npm run check
npm run check:assets
npm run build:pages
npm run preview:pages

۴. نسخه جدید را روی GitHub بفرست

بعد از بررسی Preview، با Ctrl+C آن را ببند و دستورها را یکی‌یکی اجرا کن. پوشه قدیمی پروژه‌ات را نگه دار.

git status
git add .
git commit -m "Update complete frontend and GitHub Pages asset handling"
git push origin main

۵. نتیجه انتشار را ببین

در Settings → Pages، Source باید GitHub Actions باشد. اگر از قبل همین گزینه فعال است، تغییری لازم نیست. اجرای Deploy را در تب Actions بررسی کن. بعد از موفق‌شدن Deploy، سایت را با Ctrl+F5 تازه کن.

اگر دوباره fetch first دیدی

Clone تازه بر پایه آخرین نسخه است. اگر بعد از Clone، GitHub دوباره تغییر کرد، با working tree تمیز دستور زیر را اجرا کن و سپس Push کن. اگر Conflict آمد، باید قبل از Push حل شود. برای این به‌روزرسانی force push لازم نیست.

git pull --rebase origin main
git push origin main

اجرای محلی و ادیتور پترن

برای ویرایش سایت، npm run dev را اجرا کن. بازکردن مستقیم index.html یا Live Server بخش‌های مشترک را پردازش نمی‌کند و ممکن است ظاهر ناقص دیده شود. برای میزبانی در ریشه دامنه یا بک‌اند از npm run build استفاده کن.

ادیتور مستقل فوتر: footer-pattern-studio.html. خروجی ادیتور خودکار روی سایت اعمال نمی‌شود؛ روش اعمال JSON در راهنمای ادیتور آمده است. فوتر تأییدشده قبلی در نسخه زنده حفظ شده است.
