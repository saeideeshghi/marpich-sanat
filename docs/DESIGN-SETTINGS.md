# تنظیمات ظاهر

## فاصلهٔ صفحه و اندازهٔ باکس‌ها

فایل: `src/css/layout-settings.css`.

| متغیر | کاربرد | مقدار فعلی |
| --- | --- | --- |
| `--site-gutter-desktop` | فاصلهٔ لوگو و محتوای صفحه از لبه‌ها | `clamp(40px, 4.45vw, 64px)` |
| `--site-gutter-tablet` | فاصلهٔ تبلت | `32px` |
| `--site-gutter-mobile` | فاصلهٔ موبایل | `20px` |
| `--site-gutter-compact` | فاصلهٔ عرض کمتر از 360px | `16px` |
| `--list-media-width` | عرض ستون تصویر در List از 768px به بالا | `240px` |
| `--list-card-min-height` | حداقل ارتفاع کارت List | `190px` |
| `--details-section-gap` | فاصلهٔ معرفی محصول تا مشخصات | `32px`؛ موبایل `24px` |
| `--table-cell-padding-block` | فاصلهٔ بالا/پایین هر سلول جدول | `12px` |
| `--table-cell-padding-inline` | فاصلهٔ افقی سلول جدول | `14px`؛ موبایل `10px` |
| `--table-heading-padding-block` | فاصلهٔ بالا/پایین سرستون | `20px` |
| `--table-note-padding-block` | فاصلهٔ متن توضیح زیر جدول | `14px` |

کلاس `site-frame` برای **Wrapper بیرونی** است. Grid داخلی یا کارت داخل آن، `site-frame` دیگری نمی‌گیرد.
این Wrapper عرض `100% - 2 × gutter` دارد؛ روی 1920 یا 2560px، `max-width` جداگانه به آن حاشیهٔ اضافه نمی‌دهد.
Background، پترن تزئینی و تصویر Hero می‌توانند تمام عرض باشند.
اسلایدر مشتری‌های خانه تنها استثنای محتوایی است: راست با لوگو هم‌فاصله است و سمت چپش به لبه می‌رسد.

## فونت‌ها

فایل: `src/css/type-settings.css`.

متغیرهای با پسوند `desktop`، `tablet` و `mobile` ورودی‌اند؛ مقدار فعال پایین فایل در Breakpoint مناسب انتخاب می‌شود.

| متغیرها | قسمت |
| --- | --- |
| `--hero-eyebrow-*` | عبارت کوتاه یا Breadcrumb بالای Hero |
| `--hero-title-*` | عنوان اصلی Hero |
| `--hero-description-*` | توضیح Hero |
| `--hero-top-*` | فاصلهٔ بالای متن Hero؛ بدون تغییر ارتفاع پایه |
| `--hero-bottom` | فاصلهٔ زیر محتوای Hero |
| `--card-title-*` | عنوان کارت |
| `--card-description-*` | توضیح کوتاه کارت |
| `--card-cta-*` | لینک اقدام کارت |
| `--card-tag-*` | دسته‌بندی و تگ مشخصات؛ هر سه مقدار فعلی `10px` |
| `--card-description-lines` | تعداد خط توضیح کوتاه کارت؛ فعلاً ۲ |
| `--text-body-*` | متن‌های دارای نقش `site-prose` و متن عمومی موبایل |
| `--text-control` | Input و کنترل فرم |
| `--text-table` / `--text-table-heading` | متن جدول / سرستون |

متن کامل پنل‌های خدمات و آدرس دفترها، محدود به دو خط نیست.
عنوان‌های خاص بخش‌ها و Footer در CSS همان صفحه یا `src/css/components/footer.css` هستند؛ نقش‌های جدول بالا فقط بر selectorهای مشترک خودشان اثر می‌گذارند.

برای تغییر فقط یک صفحه، مقادیرش را **در بخش Page Overrides همان فایل** تنظیم کن؛ مثال:

```css
body[data-page="projects"] {
    --hero-top-desktop: 176px;
    --card-title-desktop: 18px;
    --card-tag-desktop: 10px;
}
```

برای تغییر فقط یک بخش، روی Wrapper آن متغیر نقش را Override کن؛ مثال:

```css
.home-products-grid {
    --card-title: 19px;
    --card-description: 15px;
}
```

## ارتفاع Hero

فایل: `src/css/hero-heights.css`؛ هر صفحه ID جدا دارد، مانند `#hero-projects` و `#hero-product-details`.

```css
#hero-projects {
    --hero-height-desktop: 31rem;
    --hero-height-tablet: 31rem;
    --hero-height-mobile: 25svh;
}
```

مقادیر، حداقل ارتفاع‌اند؛ فرم و متن بلند اجازه دارند ارتفاع طبیعی بخش را بیشتر کنند.
مقدار فعلی خانه همان `44rem` فایل ورودی است. صفحه‌های داخلی همان پایهٔ `31rem` را حفظ کرده‌اند.
فاصلهٔ بالای متن داخلی در Desktop، `164px` شده؛ خانه `120px` و تماس با ما `120px` باقی مانده‌اند.

در صفحه‌های جزئیات و درباره‌ما، `src/js/components/hero.js` هم‌پوشانی کارت/تصویر با Hero را اندازه می‌گیرد.
فضای امن زیر متن Hero حفظ می‌شود؛ مقدار Margin منفی ثابتی برای جبران دوبارهٔ آن اضافه نکن.
تصویر تیم درباره‌ما تمام عرض قاب را با نسبت اصلی `1311 / 628` می‌گیرد. محدودیت خودکار ارتفاع viewport حذف شده تا کنار عکس فضای خالی ایجاد نشود؛ عکس با اسکرول طبیعی صفحه دیده می‌شود.

در تبلت فاصلهٔ بالای Hero داخلی `168px` و در موبایل `156px` است. خانه در تبلت `192px` دارد.
Hero جزئیات محصول در موبایل پایهٔ `26rem` و جزئیات پروژه `24rem` دارد؛ مقدارشان با ID همان صفحه قابل تغییر است. فاصلهٔ بالای متن محصول در موبایل `168px` است و کارت آن تا `140px` روی زمینهٔ آبی می‌آید؛ هم‌پوشانی با فضای امن زیر عنوان محدود می‌شود.

## تنظیم مستقل جزئیات پروژه

فایل `src/css/pages/project-details-settings.css` فقط روی `body[data-page="project-details"]` اثر می‌گذارد.
عنوان بخش‌ها، متن‌های کامل، عنوان و مقدار اطلاعات پروژه، فاصله‌ها، تعداد ستون‌های اطلاعات/دستاوردها و اندازهٔ آیکن‌ها در این فایل‌اند.
متغیرهای پسونددار `desktop`، `tablet` و `mobile` را تغییر بده؛ بخش پایین فایل مقدار فعال را انتخاب می‌کند.
در موبایل، کارت محصولات پروژه عنوان 16px و توضیح 14px و دستاوردها متن 14px دارند؛ این استثناها در تنظیمات تأییدشدهٔ Customizer ثبت شده‌اند. در جزئیات محصول نیز عنوان 17px و توضیح 14px است؛ توضیح اصلی کامل نمایش داده می‌شود. در هر دو صفحه، زیر ۵۲۱ پیکسل متن جدول 13px و سرستون 14px است.
خلاصهٔ پروژه روی تصویر کارخانه است: شش ستون دسکتاپ/تبلت و سه ستون در دو ردیف موبایل. متن دیدگاه کارفرما با کلاس‌های اختصاصی `project-details__testimonial-*` کامل دیده می‌شود و از محدودیت توضیحات کارت‌ها مستقل است.
در بخش فنی هر دو صفحهٔ جزئیات، زیر ۹۰۱ پیکسل تصویر بالای جدول است؛ مشخصات تکمیلی محصول بین تصویر و جدول قرار می‌گیرند.

## پترن فوتر و منوی زبان

- فایل `src/data/patterns/footer-pattern.json` مرجع فعال فوتر است. `breakpoint: 501` یعنی عرض ۵۰۰ و کمتر موبایل است.
- پروفایل Desktop: `x: -4.5`، `y: 0.1`، `width: 101.7`، `rotation: 3.9`، `opacity: 50`؛ بدون `maxWidth` یا clip اضافی.
- پروفایل Mobile: هندسهٔ ۱۲ مسیر فایل مرجع ارسالی، با Opacity برابر `24` به‌جای `10`.
- در موبایل، Stage و SVG صددرصد ارتفاع واقعی فوتر هستند؛ با تغییر متن یا فاصلهٔ فوتر نیز کل ارتفاع را می‌پوشانند. پروفایل دسکتاپ نسبت و هندسهٔ اصلی خود را حفظ می‌کند.
- هر دو پترن، پروفایل و Artwork مستقل دسکتاپ، تبلت و موبایل دارند. تب پترن Customizer هندسه، انیمیشن، مسیرها و گرادینت هر پروفایل را روی همان سایت پیش‌نمایش می‌دهد؛ ثبت و خروجی ZIP هر دو JSON پترن را هم شامل می‌شوند.
- پرچم‌ها همان SVGهای ارسالی در `public/assets/icons/flags/*-circle.svg` هستند.
- منوی زبان از `src/js/components/language.js` و `src/css/components/language.css` استفاده می‌کند. EN/AR تا وجود مسیر ترجمهٔ واقعی، متن فارسی را با برچسب زبان اشتباه نشان نمی‌دهند.
- برای اتصال مسیر ترجمه، رویداد قابل لغو `site:language-request` با `detail.language` را در adapter بگیر؛ پیش از navigation، `event.preventDefault()` را اجرا کن.

## تصاویر خدمات در عرض‌های کوچک

در عرض کمتر از ۱۱۸۰ پیکسل، تصویر با نسبت اصلی بالای متن می‌آید؛ Overlay دسکتاپ حفظ شده است.
کلاس‌های `expertise-page__artwork`، `expertise-page__card-title` و `expertise-page__card-description` مخصوص همین صفحه‌اند.
سایه و حاشیهٔ شفاف خود فایل‌های PNG با متغیرهای `--expertise-image-*` حذف می‌شود؛ عکس با Hover زوم نمی‌شود.
در عرض ۴۵۰ و کمتر، عنوان این کارت‌ها `16px` و توضیح `14px` است.

## حوزه‌های تخصصی

- متن، تصاویر، مزایا و CTA هر پنج خدمت در `expertise.html` است.
- ساختار همهٔ کارت‌ها یکسان است؛ جزئیات در HTML قرار دارند.
- رفتار باز و بسته‌شدن در `src/js/components/services.js` است.
- برای افزودن خدمت، ID کارت و ID جزئیات باید یکتا باشند و `aria-controls` به ID همان جزئیات اشاره کند.
- بدون JavaScript، جزئیات قابل خواندن‌اند؛ بعد از فعال‌شدن JS، پنل‌ها بسته می‌شوند و با کلیک یا Space باز می‌شوند.
- لینک مستقیم به ID خدمت یا جزئیات، همان خدمت را باز می‌کند.

# ویرایش زنده با Customizer

نسخهٔ فعلی یک ویرایشگر برای همهٔ صفحه‌ها دارد: `npm run customize`. راهنما در [CUSTOMIZER.md](../CUSTOMIZER.md) است.
تنظیمات تأییدشدهٔ `src/data/customizer/settings.json` و CSS تولیدشدهٔ آن روی استایل‌های پایهٔ این راهنما اولویت دارند. برای تغییر فونت و فاصله از ویرایشگر استفاده کن؛ اگر می‌خواهی دوباره فقط از فایل‌های پایه استفاده شود، تنظیم همان بخش/اندازه را در ویرایشگر حذف و تأیید کن. انتخاب مستقیم، اجزای تکراری و بازهٔ دلخواه عرض جدا هستند؛ برای یکسان شدن باکس‌ها گزینهٔ یکسان‌سازی استثناهای همان مقدار را روشن نگه دار.
