# اصلاح خوانایی و بازخورد طراحی — ۲۹ سپتامبر ۲۰۲۶

## تغییرات این نسخه

- اندازه متن‌های کوچک در HTML صفحات و کامپوننت‌ها و CSS صفحات حداقل ۱۴px شده است؛ اندازه آیکن‌های تزئینی مستقل باقی مانده است.
- متن اصلی، لینک‌ها و اطلاعات تماس فوتر ۱۶px، عنوان ستون‌ها ۱۸px و متن انتهایی ۱۴px است. کنتراست متن انتهایی افزایش یافته است.
- عبارت صحیح: «طراحی شده توسط تیم مارکتینگ شرق رایا».
- نوار مشتریان فعلاً چهار لوگوی نخست موجود را نشان می‌دهد: چهار ستون در عرض بزرگ و دو ستون در موبایل. تصاویر بزرگ‌تر شده‌اند و carousel یا حرکت خودکار ندارند. نام و هویت واقعی مشتریان با فایل‌های اصلی کنترل شود؛ فهرست کامل متعلق به فاز بعد است.
- فضای خالی بالای عکس درباره‌ما کاهش یافته است. ارتفاع عکس با فضای باقی‌مانده صفحه محاسبه می‌شود و object-fit: contain مانع برش آن است. در نمایشگر بسیار کوتاه یا zoom بالا، حداقل ارتفاع ۱۶۰px حفظ می‌شود و ممکن است اسکرول لازم باشد.
- برای جلوگیری از تداخل تغییرات بعدی، تنظیمات فوتر از تنظیمات هدر جدا شده است: `src/data/patterns/footer-pattern.json`.

## مرجع پترن و موارد باز

تنظیمات `site-pattern.json` با `settings.json` در ZIP ارسالی `pattern-final.zip` یکسان است. فایل ارسالی فقط یک طرح دارد. شکل، گرادینت و انیمیشن آن تغییر نکرده است. تا دریافت مرجع مستقل فوتر، تنظیمات فایل فوتر نیز همان خروجی تأییدشده است؛ جدا شدن فایل‌ها به معنی اعمال طرح متفاوت نیست.

تصویر مرجع فوتر در ورودی این نوبت وجود ندارد. ساختار موجود فوتر حفظ و خوانایی آن اصلاح شده؛ تطبیق دقیق ساختار و پترن متفاوت فوتر هنوز انجام نشده و به عکس یا خروجی مستقل نیاز دارد.

## اعتبارسنجی و راه‌اندازی

- `npm run check`: موفق؛ ۱۲ صفحه، کامپوننت‌ها، مسیرها و قواعد handoff.
- `npm run build`: موفق.
- پوشه `public/assets`، تصاویر اصلی و فونت Peyda در ZIP ورودی نبودند. به همین دلیل تأیید نهایی ظاهر، نسبت واقعی عکس درباره‌ما و اندازه بصری لوگوها به بازگرداندن فایل‌های اصلی نیاز دارد.
- بررسی مرورگری این اجرا انجام نشد: دانلود مرورگر آزمون ناموفق بود. گزارش‌های visual قدیمی در `docs` مربوط به نسخه‌های قبلی هستند.

پوشه اصلی `public/assets` پروژه خودتان را حفظ کنید. فایل‌های سورس این نسخه را جایگزین کنید؛ سپس `npm ci` و `npm run dev` را اجرا کنید. برای خروجی نهایی `npm run build` را اجرا کنید. هیچ فایل asset اصلی در این نسخه جایگزین یا حذف نشده است.
