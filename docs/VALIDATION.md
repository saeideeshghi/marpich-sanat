# بررسی انتشار V3

برای انتشار `3.0.0`، شمارهٔ package و lockfile و راهنمای انتشار به‌روزرسانی شدند. `npm run check` و `npm run build:pages` دوباره با موفقیت اجرا شدند. سورس صفحات و ویرایشگر همان نسخهٔ بررسی‌شدهٔ `0.5.0` است؛ نتایج بررسی آن در ادامه آمده است.

بررسی بر مبنای `backup.rar` ارسالی انجام شد. دارایی‌های اصلی که در ورودی نبودند، به‌عنوان موجود یا بررسی‌شده گزارش نشده‌اند.

| کنترل                                                        | نتیجه                       |
| ------------------------------------------------------------ | --------------------------- |
| ساختار ۱۲ صفحه، entryها، includeها، ID و لینک داخلی          | PASS                        |
| escaping محتوا، URLها و renderer کامپوننت‌ها                 | PASS                        |
| قرارداد فرم‌ها و تبدیل مسیر assets برای GitHub Pages         | PASS                        |
| همخوانی JSON قواعد و CSS تولیدی                              | PASS؛ ۱۵۹ قانون قبلی حفظ شد |
| قواعد responsive، واحدها، stateها و جلوگیری از ورودی نامعتبر | PASS                        |
| Build معمولی و Build GitHub Pages                            | PASS                        |
| Prettier برای سورس و Customizer                              | PASS                        |
| مقایسهٔ computed styles پیش/پس از پاک‌سازی                   | ۶۶ حالت منطبق؛ ۱۲ صفحه      |
| اسکرول افقی در حالت‌های مقایسه                               | صفر در هر دو نسخه           |
| Customizer محلی و ذخیرهٔ فایل                                | PASS                        |
| Customizer ساخته‌شدهٔ Static و Export ZIP                    | PASS                        |
| عرض رابط ویرایشگر در 390px                                   | بدون overflow افقی          |

برای مقایسهٔ layout، نمایش‌های 390، 640، 900، 1180 و 1440px در همهٔ صفحه‌ها بررسی شدند؛ `project-details` علاوه بر آن در 320، 500، 501، 639، 1179 و 1920px بررسی شد. ۲۷ property مربوط به چیدمان و تایپوگرافی روی المان‌های محتوا مقایسه شدند. در یک مشاهدهٔ اولیهٔ هواساز، نتیجهٔ margin پیش از تثبیت layout متفاوت بود؛ تکرار بعد از دو frame، برابری همان case را تأیید کرد. تغییر CSS برای پنهان‌کردن اختلاف انجام نشد.

آزمون Customizer شامل قانون مشترک هدر روی سه صفحه، فعال‌بودن تا 500px و غیرفعال‌بودن در 501px، Grid نامتقارن، واحد rem، کپی بین breakpointها، شبیه‌سازی hover، Undo/Redo، فیلتر property، خاموش/روشن‌کردن قانون، ذخیره، reload و رد revision قدیمی و token نامعتبر بود. Export ZIP با کنترل CRC و مسیر چهار فایل مرجع باز شد.

## تغییرات پاک‌سازی

- ۱۹ فایل قدیمی یا بدون مصرف حذف شدند و دو stylesheet نام روشن‌تر گرفتند؛ فهرست ۲۱ مسیر منسوخ در `obsolete-files.json` است.
- selectorهای CTAهای کنارگذاشته‌شده و declarationهای کاملاً یکسان حذف شدند؛ ترتیب media queryها حفظ شد.
- `settings.json` از 425,188 به 54,318 بایت رسید؛ حدود ۸۷٪ کاهش با حذف کپی artworkها. artwork اصلی در دو JSON خودش باقی است.
- Customizer به ماژول‌های schema، values، controls و picker تفکیک شد. قابلیت‌های جدید به ۹۸ property دسترسی می‌دهند.
- کلاس‌های عمومی کارت به markup اضافه شدند؛ نام‌های وابستهٔ قبلی و data-*های رفتار حفظ شدند.

## دامنهٔ بررسی دارایی‌ها

در ورودی سبک، ۱۸ مورد از ۱۷۴ مسیر موردنیاز assets موجود بود. مسیرها در `assets-manifest.json` آمده‌اند. مقایسهٔ layout در همان شرایط ورودی انجام شد؛ تصویر اصلی، PDF/CAD و فایل‌های حذف‌شده از ورودی باید از پوشه‌های قبلی کاربر تأمین شوند. `npm run check:assets` پس از Merge با نسخهٔ کامل باید دوباره اجرا شود.

فرم‌ها، Auth واقعی و مقصد ۱۱۴ لینک placeholder همان موارد باز نسخهٔ قبلی‌اند و به اتصال Backend/CMS مربوط‌اند.
