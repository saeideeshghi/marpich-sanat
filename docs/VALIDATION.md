# بررسی V3

## اصلاح انتشار در ویندوز

مبنای این اصلاح، بستهٔ نهایی مرحلهٔ قبل با SHA256 زیر است؛ تمام فایل‌های `src` و HTML، تنظیمات و پترن‌ها با این بسته یکسان‌اند:

`5340e4fe40960b8ea3021502f6110cdc91e05012f9004ae61f9b853b17dff8ce`

- ورود اشتباه قانون ذخیره‌شدهٔ `--header-fixed-scroll-threshold` به مرجع روی مسیر ویندوز بازتولید شد؛ پس از اصلاح، اختلاف قرارداد صفر است.
- ۱۸۹ نام متغیر و تمام اطلاعات تعریف/مصرف در چهار ترکیب Windows/POSIX × LF/CRLF یکسان‌اند؛ ترتیب معکوس فایل‌ها نیز نتیجه را تغییر نمی‌دهد. CSS تولیدی وارد مرجع نمی‌شود و رویداد تغییر سورس با مسیر ویندوز درست کار می‌کند.
- مسیر اجرای npm با Node، مسیرهای دارای فاصله و جایگزین محدود `cmd.exe` بررسی شدند. اجرای واقعی npm CLI از Node بدون `shell:true` موفق بود؛ آزمون روی Linux با شبیه‌سازی مسیر ویندوز اجرا شد.
- Check، Format، Build عادی و Build مخصوص Pages موفق‌اند. آزمون Git از مخزن محلی استفاده می‌کند و هیچ Push خارجی انجام نشده است.
- گزارشی جداگانه در `windows-publish-checks.json` ثبت شده است. گزارش‌های پترن، منو و تصویر زیر مربوط به مرحلهٔ قبلی‌اند؛ در این اصلاح ابزار انتشار تغییر کرده و سورس ظاهر سایت ثابت مانده است.

## حفظ سورس

مسیرها، رنگ‌ها، استاپ‌های گرادینت و جای پترن با مبنا برابرند. فقط پیش‌فرض‌های حرکت عمداً آرام‌تر شده‌اند و حمایت پیکسلی اضافه شده است. مقدار آزمایشی در قوانین ذخیره‌شده نیست: ۱۶۰ قانون اصلی و CSS تولیدی حفظ شده‌اند. فایل‌های گرید، دادهٔ محصولات، CTA، تصویر درباره‌ما، hero.js و helper گیت برابر مبنا هستند. فهرست دقیق و هش‌ها در `stable-preservation.json` ثبت شده‌اند.

گزارش‌های تازه: `stable-pattern-motion-checks.json`، `stable-pattern-raster-checks.json`، `stable-pattern-editor-checks.json`، `stable-header-layout-checks.json`، `stable-grid-image-checks.json` و `stable-pages-checks.json`. گزارش هندسهٔ ribbon، کاستومایزر منوی قبلی و CTA/متغیرهای مرورگر سابق، سوابق نسخهٔ مبنا هستند؛ الگوریتم ribbon و رفتار CTA در این اصلاح تغییر نکرده‌اند. سایر گزارش‌ها نیز سوابق مراحل قبلی‌اند. آزمون helper انتشار از مخزن Git محلی استفاده می‌کند؛ Push خارجی انجام نشده است.

## دارایی‌ها و تحویل

تصاویر و فونت‌های اصلی در ZIP مبنا نبودند. آزمون تصویر/گرید از SVG آزمایشی فقط در مرورگر استفاده کرده؛ این fixtureها داخل تحویل نیستند. پوشه‌های عکس، فونت و `public` پروژهٔ اصلی را حفظ کن. Build عادی و Build مخصوص Pages بررسی می‌شوند؛ بررسی کامل فایل‌های تصویری با `npm run check:assets` روی پروژهٔ دارای دارایی‌ها اجرا می‌شود. دو طرح پترن ثابتِ جدید دسکتاپ هنوز ارسال نشده‌اند.
