# گزارش بازبینی ۲۰۲۶-۰۹-۲۷

ورودی: 0(1).zip؛ نسخه نهایی سورس: 0.3.3.

## تغییرات

1. فایل تنظیمات پترن با `pattern-final/settings.json` یکسان شد.
2. renderer پترن به رفتار خروجی Pattern Studio برگشت: سوییچ مستقیم mobile/desktop در 463px و همان wave + moving light مرجع.
3. interpolation بین 463 و 1180، حداقل stroke اجباری، `non-scaling-stroke`، کاهش opacity/light فوتر و کشیدگی عمودی SVG حذف شدند.
4. برای حفظ جایگاه درصدی مرجع، پترن داخل stage authored با ارتفاع 430px دسکتاپ و 404px موبایل اجرا می‌شود.
5. integration سایت فقط background/text دموی Pattern Studio را حذف می‌کند؛ رنگ، گرادینت، مسیر، حرکت و نور override نمی‌شوند.
6. سند تحویل و README با قرارداد جدید پترن هماهنگ شدند.

## مرز تحویل

هیروی تصویری خانه پترن مشترک هدر ندارد و این رفتار حفظ شده است. پترن فوتر دیگر برای پوشاندن اجباری کل ارتفاع stretch نمی‌شود؛ هندسه مرجع حفظ شده است. هندسه CTA خانه، Expertise و جدول فنی دست‌نخورده مانده است.

assets/fonts عمداً از ورودی حذف شده‌اند. نبود ۱۵۷ مرجع عمومی در ZIP خطای سورس محسوب نشده و هیچ تصویر ساختگی به جای آن‌ها اضافه نشده است. تأیید نهایی تصاویر/فونت و برش‌ها پس از بازگشت فایل‌های واقعی لازم است.

APIها، routeهای CMS، ثبت واقعی فرم، جستجو/pagination، مقصد placeholderها، مدل سه‌بعدی و حساب/خروج در این بازبینی پیاده نشده‌اند. قرارداد موجود و مسیر اتصال آن‌ها در سند آمده است.
