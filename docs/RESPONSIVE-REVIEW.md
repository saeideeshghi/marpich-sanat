## بررسی انجام‌شده

- بررسی ساختار ۱۲ صفحه، importها، شناسه‌ها، اجزای تکراری، لینک داخلی و Select جستجوی فارسی با `npm run check`.
- ساخت خروجی استاندارد با `npm run build` و خروجی GitHub Pages با `npm run build:pages`.
- ۹۴ سناریوی چیدمان: همهٔ ۱۲ صفحه در عرض‌های 320، 375، 768، 1180، 1440، 1920 و 2560px؛ همچنین دو سوی مرزهای 551/552، 616/617 و 1013/1014px در بخش مرتبط.
- کنترل برابر بودن Gutter با Header، نبودن اسکرول افقی، تگ 10px، استثنای لبهٔ چپ مشتری‌ها و مخفی‌شدن توضیح فرایند.
- بررسی تصویر کامل درباره‌ما در viewport با ارتفاع 900px. در viewport خیلی کوتاه ممکن است اسکرول طبیعی لازم شود.
- باز و بسته‌شدن مستقل پنج خدمت با Click و Space، بازشدن لینک مستقیم و خوانایی محتوای کامل بدون JavaScript.
- انتخاب، جستجوی گزینه و Clear فیلترهای سه کاتالوگ؛ مقدار Select اصلی فرم حفظ می‌شود.
- ۹ سناریوی List در پروژه‌ها، محصولات و صنایع، در عرض‌های 1024، 1440 و 1920px.
- کنترل هر دو جدول در 375، 1024، 1440 و 1920px: سلول‌ها و متن زیر جدول روی هم نمی‌افتند؛ Padding سلول 12px است.
- بررسی تکمیلی معرفی/جدول جزئیات محصول در ۱۲ عرض از 320 تا 2560px و آدرس کامل تماس در 320، 375، 616 و 617px.
- بررسی تصویری صفحات در موبایل و Desktop، پنل باز خدمات، حالت List، Hover لوگو و جدول‌های جزئیات.

این بررسی‌ها روی خروجی محلی Chromium انجام شده‌اند؛ استقرار مجدد سایت آنلاین جزو این بسته نیست.

## موارد محتوایی و اتصال

- برای بررسی ظاهری، تصاویر موجود سایت فعلی استفاده شدند. آن تصاویر اصلی در ZIP تکرار نشده‌اند؛ بسته را با پروژهٔ دارای Assets خودتان **Merge** کنید.
- دارایی‌های همراه ورودی و لوگوی جدید `public/assets/logos/projects/blue-waves.png` در بسته هستند. مرجع لوگوی موج‌های آبی: سایت رسمی `wwlpark.com`.
- `npm run check:assets` همهٔ مراجع تصاویر، فونت‌ها و دانلودها را بررسی می‌کند. PDF و ZIP دانلود محصول در مجموعهٔ Assets بررسی‌شده موجود نیستند: `northair-pro-flow-datasheet.pdf` و `northair-pro-flow-cad.zip`. فایل PDF در سایت فعلی نیز قابل دریافت نبود. فایل‌های واقعی را در `public/assets/documents/product-details/` قرار دهید.
- لینک‌های محتوایی `#` موجود هنوز باید به مقصد واقعی متصل شوند. آن‌ها در Check گزارش می‌شوند و مانع ساخت Frontend نیستند.
- رفتار محلی فرم‌ها و کاتالوگ فعال است؛ ثبت واقعی درخواست‌ها، نتیجهٔ جستجوی آنلاین، Auth و دادهٔ نهایی به Backend و محتوای واقعی نیاز دارند.
- متن خدمات، نمونه است و می‌توانید آن را مستقیم در `expertise.html` جایگزین کنید.
- تصویر کوچک‌تر درباره‌ما هنوز ارائه نشده؛ تصویر فعلی حفظ و نحوهٔ نمایش آن اصلاح شده است.

مقصدهای فرم و قرارداد رویدادها در README ریشه توضیح داده شده‌اند.
