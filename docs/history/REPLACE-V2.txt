اصلاحات پترن و کارت‌ها ـ نسخه v2، بازبینی دوم ۲ اکتبر ۲۰۲۶

این ZIP یک بسته آپدیت برای پروژه فعلی است.
محتویات داخل ZIP را در ریشه پروژه قبلی، کنار package.json، کپی و Replace کن.
پوشه‌های src و public باید با نسخه فعلی ادغام شوند؛ assets و فونت‌های موجود را حذف نکن.

برای ارسال هر آپدیت، در ترمینال VS Code و همان پوشه قبلی اجرا کن:

.\PUSH-GITHUB.cmd

وقتی Actions سبز شد، سایت را با Ctrl + F5 باز کن.
راهنمای کامل و رفع خطاها: GITHUB-UPLOAD.md
دستورهای کوتاه: GITHUB-PUSH.txt
گزارش این بازبینی: docs/2026-10-02-PATTERNS-CARDS.md
