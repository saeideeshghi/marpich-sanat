- `npm ci --ignore-scripts`: موفق؛ Node 24.19.0. Build بعدی با dependencyهای نصب‌شده موفق بود.
- `npm run check`: موفق برای ۱۱ صفحه؛ ساختار/entry/ID/لینک داخلی، escape متن و رگرسیون URL، SearchPanel و FAQ.
- بررسی syntax با `node --check`: موفق برای 29 فایل JS.
- `npm run build`: موفق؛ ۱۱ صفحه و manifest تولیدی ساخته شد. هشدار asset غایب باقی است.
- بررسی assetها شامل JSON: ۹ از ۱۵۷ مرجع حاضر؛ ۱۴۸ مفقود. **check:assets ناموفق**؛ علت در ورودی است و قبل از انتشار باید رفع شود.
- ۲۹۲ لینک خالی یا `#` در HTMLهای renderشده شناسایی شد؛ شامل تکرار partialها.
- مقایسهٔ بایت با ZIP ورودی: همهٔ فایل‌های src/css و JSON دادهٔ صفحه بدون تغییر.

## بررسی‌نشده / محدودیت

- تصاویر و فونت‌های اصلی در ورودی غایب‌اند؛ برابری screenshot فقط بین دو خروجی با همین دارایی ناقص است، نه تطبیق با Figma یا تأیید نهایی طرح.
- backend/.NET/CMS، دیتابیس، پیامک، ایمیل، OTP واقعی، cookie session، CSRF واقعی و upload سرور وجود ندارند؛ آزمون endpointهای واقعی انجام نشده.
- همهٔ سناریوهای Auth/API، محدودیت فایل ۲۰ MiB، drag/drop و همهٔ breakpointها در این نوبت دوباره تست نشده‌اند. گزارش قدیمی شاهد اجرای جدید نیست.
- Safari/iOS و دستگاه واقعی آزمایش نشده‌اند. انیمیشن pattern در تست pixel به‌دلیل reduced-motion متوقف بود؛ این تست تأیید روانی انیمیشن نیست.
- نمونه‌های Razor/API در سند راهنما هستند؛ پروژهٔ دات‌نت اجرا یا compile نشده است.
- آماده‌سازی حالت چاپ آزمایش شده؛ صفحه‌بندی همهٔ صفحات PDF خروجی تضمین نشده، فایل اصلی قابل تحویل HTML است.
