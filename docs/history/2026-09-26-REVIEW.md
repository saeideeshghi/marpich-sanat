# گزارش بازبینی و اصلاحات

تاریخ: ۲۰۲۶-۰۹-۲۶ · ورودی: 122121(3).zip

## اصلاحات عملکردی محدود

1. فایل پیوست RFQ دارای name=attachment شد تا FormData واقعاً آن را بگیرد.
2. SearchPanel از id داده استفاده می‌کند؛ FAQ از href/linkText داده استفاده می‌کند.
3. check-assets فایل‌های JSON را هم می‌خواند؛ ۱۴ مرجع پنهان قبلی به گزارش اضافه و manifest بازسازی شد.
4. consultation:submit و rfq:submit با FormData و قرارداد cancelable اضافه شد؛ fallback در نبود adapter حفظ است.
5. label فایل پس از پاک‌شدن انتخاب برمی‌گردد؛ fallback خطای cached تصاویر Industries/Textile اصلاح شد.
6. URLهای href/image علاوه بر escape متن، scheme کنترل‌شده دارند؛ تست رگرسیون اضافه شد.
7. build.manifest برای اتصال assetهای hashشده به Razor فعال شد.

## نگهداری و توضیحات

- کامنت‌های مسئولیت، lifecycle، محدودیت‌ها و قرارداد اتصال در فایل‌های کلیدی اضافه شد.
- README به وضعیت جاری بازنویسی شد؛ متن قبلی و گزارش‌های قدیمی جدا نگه داشته شدند.
- docs/backend-handoff.html سند فارسی مستقل با راهنمای فایل، صفحه، مدل داده، رویداد، Auth، RFQ، Razor و انتشار است.
- CSS و JSON صفحات تغییر نکرده‌اند. پاک‌سازی گستردهٔ cascade به‌دلیل نبود assetهای اصلی انجام نشده؛ برای تحویل فعلی لازم نبود.

## اولویت‌های باقی‌مانده

- بازگرداندن ۱۴۸ asset غایب و بررسی نهایی با فونت/تصویر اصلی.
- پیاده‌سازی backend فرم، Auth، جستجو و pagination؛ schema و endpointهای غیر Auth در سند پیشنهادی‌اند.
- تعیین راه تماس برای فرم‌هایی که فقط fullName/company/message دارند و اجباری‌کردن فیلدهای لازم.
- جایگزینی ۲۹۲ placeholder خروجی، count و chips نمایشی، امتیاز ثابت و مسیر دانلودها.
- تکمیل حساب کاربری، خروج، زبان دوم، CAD و 3D در صورت جزو scope بودن.
