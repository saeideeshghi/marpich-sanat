# خطوط مرجع و فاصله مشتری‌ها — نسخه نهایی v2

این بسته، اصلاحات قبلی صفحه اصلی و فوتر را هم شامل می‌شود. محتوای ZIP را کنار `package.json` کپی کنید و فایل‌های هم‌نام را Replace کنید.

## تغییرات این بازبینی

- خط زیر منو از خود `Line.png` ارسالی استفاده می‌کند؛ اندازه 38×1px، رنگ و شفافیت پیکسل‌ها بدون تغییر است. فایل در `public/assets/icons/ui/nav-active-line.png` قرار دارد.
- جداکننده مشتری‌ها از خود `Line 5.png` ارسالی استفاده می‌کند؛ اندازه اصلی 1×83px و در موبایل ارتفاع 64px دارد. فایل در `public/assets/icons/ui/partners-separator.png` قرار دارد.
- عرض باکس مشتری‌ها دیگر از تقسیم عرض صفحه محاسبه نمی‌شود. هر باکس متناسب با تصویر داخلش عرض می‌گیرد؛ فضای خالی باکس‌ها حذف شده است.
- فاصله بین باکس‌ها در موبایل 8px، تبلت 10px و دسکتاپ 12px است.
- اندازه‌های طبیعی SVG لوگوها در داده صفحه ذخیره شده‌اند تا پیش از بارگذاری تصاویر هم چیدمان پایدار باشد. renderer برای داده‌های قدیمی که این اندازه‌ها را ندارند، مقادیر پیش‌فرض قبلی را نگه می‌دارد.
- حرکت نوار به اندازه دقیق عرض یک گروه انجام می‌شود. تعداد کپی‌های نمایشی بر اساس عرض نوار تنظیم می‌شود تا نمایشگر بزرگ هم در انتهای چرخه فضای خالی نداشته باشد. کپی‌ها برای screen reader مخفی‌اند.
- در حالت `prefers-reduced-motion` حرکت غیرفعال است و لوگوهای اصلی به صورت ثابت نمایش داده می‌شوند.

## فایل‌های جدید/اصلاح‌شده در این بازبینی

| مسیر | کاربرد |
| --- | --- |
| `src/css/components/site.css` | استفاده از PNG مرجع خط منو |
| `src/components/partners.html` | استفاده از PNG جداکننده مشتری‌ها |
| `src/css/pages/home.css` | عرض طبیعی لوگوها، فاصله و اندازه responsive |
| `src/js/components/partners.js` | اندازه‌گیری چرخه و کپی‌های لازم برای حرکت پیوسته |
| `src/data/pages/home.json` | اندازه طبیعی هشت لوگو |
| `build/components.js` | استفاده از اندازه تصویر، با fallback برای داده قبلی |
| `public/assets/icons/ui/*.png` | دو فایل اصلی ارسالی |

## بررسی خروجی

- `npm run check` پاس شد؛ ساختار ۱۲ صفحه، includeها، شناسه‌ها، importها و لینک‌های داخلی درست‌اند.
- `npm run build:pages` پاس شد؛ مسیر PNG خط منو در خروجی `/marpich-sanat/assets/icons/ui/nav-active-line.png` است.
- نوار مشتری‌ها در عرض‌های 320، 375، 560، 639، 640، 768، 1024، 1179، 1180، 1440، 1920 و 2560px بررسی شد.
- خطای runtime، تصویر خراب در نوار یا سرریز افقی ثبت نشد.
- عرض باکس هر لوگو با عرض تصویرش برابر است؛ باکس کشیده اضافی وجود ندارد.
- عرض گروه‌های تکراری یکسان است. ابتدای چرخه، میانه و آخرین فریم بررسی شدند؛ فضای خالی در محدوده نوار دیده نمی‌شود.
- در عرض 1440px هشت لوگوی اصلی به همراه لبه کپی بعدی در نوار جا می‌گیرند.
- هر دو PNG با فایل‌های ارسالی مقایسه شدند و بایت‌به‌بایت یکسان‌اند.

## انتشار

```bash
npm run check
npm run build:pages
git add .
git commit -m "Finalize home page reference lines and compact partner strip"
git push origin main
```

پس از موفق‌شدن GitHub Actions، صفحه آنلاین را با `Ctrl+F5` تازه کنید. جزئیات سایر اصلاحات صفحه اصلی در گزارش قبلی `2026-10-03-HOME-POLISH.md` ثبت شده‌اند.
