# نقشه سورس و محل تنظیمات

این پروژه ۱۲ صفحه HTML مستقل دارد و با Tailwind CSS 4، CSS اختصاصی هر صفحه و ES Modules اجرا می‌شود. Vite هنگام dev/build بخش‌های مشترک را از templateها و JSON می‌سازد. HTML نهایی به JavaScript برای ساخت محتوا وابسته نیست.

## فایل‌های اصلی

| مسیر | مسئولیت | زمان تغییر |
| --- | --- | --- |
| HTMLهای ریشه | ساختار و محتوای اختصاصی صفحات، ID هیرو و includeها | تغییر متن یا ترتیب بخش‌های یک صفحه |
| `build/pages.js` | فهرست صفحه‌ها، entryهای Vite و منوی فعال | افزودن صفحه یا تغییر گروه منوی فعال |
| `src/components/` | هدر، فوتر، منوی موبایل، فرم‌ها و templateهای کارت | تغییر مشترک در چند صفحه |
| `src/data/pages/` | داده کارت‌ها، فرم جست‌وجو، FAQ و محتوای includeها | تغییر داده‌ای که در HTML مستقیم نوشته نشده |
| `src/css/main.css` | Tailwind، فونت‌ها، رنگ‌ها و استایل اجزای عمومی | تغییر پایه مشترک سایت |
| `src/css/pages/` | چیدمان و تصاویر اختصاصی هر صفحه | تغییر ظاهر یک صفحه |
| `src/css/type-settings.css` | فونت‌ها، تعداد خطوط توضیح کارت و فاصله متن هیرو | تغییر اندازه‌ها، مشترک یا بر اساس `data-page` |
| `src/css/hero-heights.css` | حداقل ارتفاع هر صفحه بر اساس ID هیرو | تغییر جداگانه ارتفاع دسکتاپ/تبلت/موبایل |
| `src/css/components/card-type.css` | نقش‌های مشترک عنوان، توضیح، CTA و تگ کارت | تغییر رفتار تایپوگرافی کارت‌ها |

| `src/js/main.js` | مقداردهی رفتارهای مشترک | افزودن رفتار مشترک؛ entry صفحه را اینجا import نکنید |
| `src/js/components/` | منو، کاتالوگ، فرم، FAQ، اسلایدر و پترن | تغییر یک رفتار مشترک |

| `src/js/pages/` | import استایل‌ها و رفتار اختصاصی صفحه | تغییر رفتار محلی یک صفحه |

| `vite.config.js` و `build/public-*.js` | ورودی‌های build، تجمیع assets و مسیر Pages | تغییر روش ساخت یا محل انتشار |
| `tools/footer-pattern-studio.html` | ادیتور مستقل تنظیم پترن | آماده‌سازی و بررسی تنظیمات پترن |

## ترتیب لایه‌های CSS

entry هر صفحه ابتدا `main.css` و سپس استایل اختصاصی صفحه را وارد می‌کند. قواعد تکمیلی کارت‌ها و جدول‌ها در entry یا stylesheet همان صفحه قرار دارند. `responsive.css` آخر وارد می‌شود و به ترتیب قواعد کارت‌ها، تنظیم فونت، ارتفاع با ID، قواعد هیرو و تایپوگرافی نقش‌های کارت را می‌گیرد. ترتیب فعلی importها بخشی از قرارداد ظاهر است؛ قواعد مشترک را دوباره در فایل صفحه کپی نکنید.

برای اندازه‌ها از [TYPE-SETTINGS.md](TYPE-SETTINGS.md) استفاده کنید. Index فعلاً ارتفاع پایه `44rem` دارد؛ متغیر `--home-hero-content-margin-top` در بلوک `home` مقدار دستی `105px` را نگه می‌دارد. صفحات داخلی همان ارتفاع پایه قبلی را دارند.

Breakpoints فعلی: موبایل تا `639px`، تبلت `640–1179px` و دسکتاپ از `1180px`.

## رفتار فرم‌ها و اتصال بک‌اند

| رویداد | داده | رفتار موجود |
| --- | --- | --- |
| `consultation:submit` | `{ form, formData }` | اعتبارسنجی native؛ فرم‌های موبایل/دسکتاپ ورودی‌ها و Reset را همگام می‌کنند |
| `rfq:submit` | `{ form, formData }` | attachment اختیاری، بررسی فرمت و محدودیت ۲۰ MiB در مرورگر |
| `catalog:search` | object تخت از نام/مقدار فیلدها | انتخاب گزینه native را ثبت می‌کند؛ تایپ صرفاً گزینه‌های دراپ‌داون را فیلتر می‌کند |
| `catalog:advanced` | بدون payload اضافه | hook فیلترهای تکمیلی |

این رویدادها cancelable هستند. adapter باید پیش از `await`، `preventDefault()` را اجرا کند و وضعیت loading/error/success را خودش مدیریت کند. اعتبارسنجی و ذخیره فایل در سرور همچنان لازم است. قراردادها و جزئیات Razor/Auth در [backend-handoff.html](backend-handoff.html) هستند.

## قالب‌بندی و بررسی

تنظیم formatter در ریشه پروژه قرار دارد. indentation HTML/CSS/JS چهار فاصله و JSON دو فاصله است. ترتیب کلاس‌های Tailwind، declarationهای CSS و importها حفظ می‌شود. HTML با حساسیت `strict` به whitespace قالب‌بندی شده تا چیدمان inline تغییر نکند. پروژه dependency جدید ندارد؛ برای قالب‌بندی می‌توانید همان نسخه formatter استفاده‌شده در بازبینی را موقت اجرا کنید:

```bash
npx --yes prettier@3.5.3 --check .
npx --yes prettier@3.5.3 --write .
npm run check
npm run check:assets
npm run build:pages
```

`--write` سورس را قالب‌بندی می‌کند. پوشه‌های دارایی، خروجی build، مستندات تاریخی و manifestهای تولیدشده از formatter کنار گذاشته شده‌اند. برای تغییر اندازه یا breakpoint، فقط فایل تنظیم مربوط را عوض کنید و صفحه مرتبط را در عرض‌های ۳۹۰، ۹۰۰ و ۱۴۴۰ بررسی کنید.
