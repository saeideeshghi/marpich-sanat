هر بار بعد از ادغام اصلاحات، در ترمینال VS Code و ریشه همان پروژه اجرا کن:

.\PUSH-GITHUB.cmd

ریپو: saeideeshghi/marpich-sanat
Branch: main
Actions: https://github.com/saeideeshghi/marpich-sanat/actions
سایت: https://saeideeshghi.github.io/marpich-sanat/index.html

مراحل دستی؛ دستورها را یکی‌یکی اجرا کن و بعد از خطا توقف کن:

git status
npm.cmd run check
npm.cmd run build:pages
git add -A
git commit -m "Update v2 frontend"
git pull --rebase origin main
git push origin main

وقتی Actions سبز شد، سایت را با Ctrl + F5 باز کن.
اگر پوشه Git ندارد یا Conflict دیدی، GITHUB-UPLOAD.md را بخوان.
تگ قدیمی v2.0.0 جابه‌جا نمی‌شود؛ سایت از آخرین main منتشر می‌شود.
