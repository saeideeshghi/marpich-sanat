# ادیتور پترن فوتر

`footer-pattern-studio.html` را مستقیم در مرورگر باز کنید؛ آفلاین و بدون نصب اجرا می‌شود.

## طراحی

1. «موبایل» یا «دسکتاپ» را انتخاب کنید. عرض آزمایش، عرض واقعی قاب است؛ کوچک‌نمایی تصویر برای جا شدن در پنجره، اندازه‌های خروجی را تغییر نمی‌دهد.
2. جای‌گذاری، ارتفاع بوم، مقیاس، چرخش، opacity و محوشدگی را تنظیم کنید. تنظیمات دو پروفایل مستقل‌اند.
3. در بخش «تنظیمات هر خط»، مسیر موردنظر را انتخاب کنید. رنگ‌ها، گرادینت، جابه‌جایی و سهم موج و نور قابل ویرایش‌اند. «فقط این خط» صرفاً کمکِ پیش‌نمایش است.
4. «توقف»، «از ابتدا» و نوار زمان برای بررسی فرم در یک لحظه هستند. این وضعیت‌های پیش‌نمایش وارد JSON نمی‌شوند. برای دیدن هندسه بدون موج و نور، نوع حرکت را «ثابت» انتخاب کنید.
5. «خروجی تنظیمات» را بگیرید؛ JSON را می‌توان دوباره وارد ادیتور کرد. «برگشت» و «تکرار» تغییرات طراحی را بازیابی می‌کنند.

شفافیت مرجع موبایل ۱۰٪ است؛ همان `opacity="0.1"` فایل ارسالی. اگر برای طراحی وضوح بیشتری لازم دارید، «وضوح ۵۰٪» شفافیت پروفایل فعال را تغییر می‌دهد. این تغییر در خروجی ثبت می‌شود؛ با «برگشت» قابل بازگشت است.

## اعمال در سایت

خروجی `footer-pattern.json` را جایگزین `src/data/patterns/footer-pattern.json` کنید و `npm run build` را اجرا کنید. تمام فوترها از این فایل مشترک استفاده می‌کنند. فایل هدر `src/data/patterns/site-pattern.json` مستقل است.

فایل `footer-pattern-draft.json` نقطه شروع همین ادیتور است. تنظیمات فعلی فوتر سایت در این تحویل با این پیش‌نویس جایگزین نشده‌اند؛ ادیتور برای طراحی آن آماده است.

## فایل‌ها و خروجی‌ها

| فایل / خروجی | کاربرد |
| --- | --- |
| `footer-pattern-studio.html` | ادیتور مستقل همراه renderer، طرح‌ها و تصویر مرجع |
| `footer-pattern-draft.json` | تنظیمات اولیه؛ ۱۲ مسیر عمودی موبایل و ۱۰ مسیر دسکتاپ مرجع |
| `footer-mobile-reference.svg` | SVG کامل ارسالی موبایل، بدون تغییر |
| خروجی JSON | تنظیمات کامل، جای‌گذاری و انیمیشن هر دو پروفایل؛ برای اتصال به سایت |
| خروجی HTML | پیش‌نمایش آفلاینِ متحرک و واکنش‌گرا؛ برای بررسی و اشتراک طرح |
| خروجی SVG | شکل خطوط در لحظه فعلی؛ جای‌گذاری و crop قاب در این فایل نیست |

SVG ورودی باید `viewBox` با مبدا صفر، مسیرهای M/L/C/Z و `linearGradient` با `userSpaceOnUse` داشته باشد. transform باید قبلاً در مختصات مسیر اعمال شده باشد. فایل ارسالی این شرایط را دارد؛ ماتریس‌های CSS آن دوباره روی مسیرها اعمال نمی‌شوند. SVG پشتیبانی‌نشده تنظیمات موجود را تغییر نمی‌دهد.

در مرورگرهای دارای ذخیره محلی، تغییرات خودکار نگه داشته می‌شوند. برای انتقال طرح به دستگاه دیگر یا نگهداری مطمئن، خروجی JSON بگیرید.
