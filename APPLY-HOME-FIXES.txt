این ZIP بسته اصلاحات سورس فعلی پروژه است.
محتویات ZIP را داخل ریشه پروژه، کنار package.json، کپی کنید.
فایل‌های هم‌نام را Replace کنید؛ پوشه پروژه و assets موجود را حذف نکنید.

پس از جایگزینی:
npm run check
npm run build:pages
git add .
git commit -m "Polish home page, footer and responsive cards"
git push origin main

انتشار با workflow فعلی GitHub Actions انجام می‌شود.
پس از موفق‌شدن Actions، سایت را با Ctrl+F5 تازه کنید.
