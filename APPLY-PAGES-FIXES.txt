اصلاحات فونت و هیرو مارپیچ صنعت — نسخه ۵

فایل‌ها را با همین مسیرها در ریشه پروژه، کنار package.json کپی کنید.
فایل‌های هم‌نام را Replace کنید؛ پوشه‌های assets، public و بقیه پروژه را حذف نکنید.
مبنا: نسخه فعلی main با commit زیر:
f2a92125903b7feeda2a5c5905afefec38d29583
استایل‌های دستی خارج از اصلاحات درخواستی حفظ شده‌اند.

برای تغییر سایزها، فقط این فایل را باز کنید:
src/css/type-settings.css
مقادیر مشترک بالای فایل هستند؛ تغییر مخصوص هر صفحه در بخش PAGE OVERRIDES قرار می‌گیرد.
راهنمای کامل و جدول سایزها:
docs/TYPE-SETTINGS.md

موبایل تا 639px، تبلت 640 تا 1179px و دسکتاپ از 1180px است.
ارتفاع پایه دسکتاپ/تبلت 31rem و حداقل موبایل، طبق انتخاب شما، 25svh است.
هیرو با متن بلند یا فرم جست‌وجو به اندازه محتوا بزرگ می‌شود؛ متن بریده یا اسکرولی نمی‌شود.
برای صفحه‌های بدون متن توضیحی، هیچ پاراگراف جدیدی اضافه نشده است.

اجرا:
npm run dev -- --host 127.0.0.1 --port 3000
آدرس Local نمایش‌داده‌شده در ترمینال را باز کنید.

بررسی و انتشار:
npm run check
npm run build:pages
git add .
git commit -m "Centralize hero typography and fix header and article layouts"
git push origin main

پس از موفق‌شدن GitHub Actions، صفحه را با Ctrl+F5 تازه کنید.
Dependency جدیدی اضافه نشده و package.json/package-lock.json تغییر نکرده‌اند.
