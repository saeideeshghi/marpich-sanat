سورس کامل بررسی‌شده مارپیچ صنعت — نسخه ۸

مبنای بسته آخرین main گیت‌هاب در زمان بررسی است:
505f425e56cdced292d213b2da05f7913281a2f0

این ZIP سورس کامل پروژه را دارد؛ فقط patch یا فایل‌های تغییرکرده نیست.
پوشه‌های assets، public/assets، fonts، public/fonts، عکس‌های پیش‌نمایش مستندات، node_modules، dist، .cache و .git داخل بسته نیستند.

جایگزینی:
۱. از پوشه فعلی پروژه یک کپی نگه دارید.
۲. فایل‌های ZIP را با همان مسیرها در ریشه همان پروژه، کنار package.json، کپی کنید.
۳. فایل‌های هم‌نام را Replace کنید؛ پوشه‌های assets، public/assets، fonts و public/fonts موجود را حذف نکنید.
۴. فایل‌های پیکربندی formatter را هم از ZIP کپی کنید.
۵. assets موجود در سیستم شما استفاده می‌شوند؛ لازم نیست آن‌ها را دوباره از این بسته دریافت کنید.

برای یک Clone تازه، اول سورس را Clone کنید و assets و fonts اصلی خود را در مسیر قبلی بگذارید؛ سپس فایل‌های بسته را ادغام کنید.

تغییرات دستی حفظ‌شده:
ارتفاع پایه Index در دسکتاپ، تبلت و موبایل 44rem است.
فاصله اضافه بالای محتوای هیروی Index همان 105px است.
فونت توضیح هیرو 22/18/18px و سایزهای کارت‌ها حفظ شده‌اند.
چیدمان فعلی در ۱۲ صفحه و ۹ عرض با baseline همین main مقایسه شده است.

محل تنظیم‌ها:
ارتفاع هر صفحه با ID:
src/css/hero-heights.css
فونت‌ها، تعداد خطوط کارت و فاصله بالای محتوای هیروی خانه:
src/css/type-settings.css
استایل چیدمان اختصاصی:
src/css/pages/

اصلاحات این نسخه:
قالب‌بندی یکدست HTML، CSS، JavaScript و JSON سورس.
مسیر درست تصاویر fallback در GitHub Pages.
تطبیق فارسی/عربی و نیم‌فاصله در جست‌وجوی مقالات و دراپ‌داون‌ها.
Reset هماهنگ فرم‌های مشاوره موبایل/دسکتاپ.
بازگشت برچسب فایل RFQ به حالت اولیه بعد از Reset.
بررسی ID هیرو، مسیرهای Pages و قواعد تطبیق متن.
بررسی assets از سورس و HTML واقعی، بدون URLهای تست یا manifest قدیمی.

اجرا در Windows:
npm.cmd ci
npm.cmd run check
npm.cmd run check:assets
npm.cmd run dev

آدرس Local نمایش‌داده‌شده در ترمینال را باز کنید؛ بازکردن مستقیم HTML با file:// یا Live Server، includeها را پردازش نمی‌کند.

ساخت نسخه Pages:
npm.cmd run build:pages
npm.cmd run preview:pages

اگر node_modules قبلی نصب است، dependency جدیدی اضافه نشده و package-lock.json تغییر نکرده است.

بررسی دارایی‌ها در ریپوی فعلی فقط یک مورد مفقود دارد:
public/assets/documents/product-details/northair-pro-flow-datasheet.pdf
اگر PDF اصلی را روی سیستم دارید، با همین مسیر حفظ یا اضافه کنید. فایل ساختگی جایگزین نشده است.

پیش از Push، راهنمای GITHUB-UPLOAD.md را اجرا کنید.
پروژه از GitHub Pages روی main منتشر می‌شود؛ dist را دستی جایگزین سورس نکنید.
