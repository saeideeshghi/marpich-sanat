اصلاحات صفحات داخلی مارپیچ صنعت — نسخه ۳

این ZIP بسته به‌روزرسانی سورس است و فقط فایل‌های اصلاح‌شده را دارد.
فایل‌ها را با مسیرهای فعلی‌شان در ریشه پروژه، کنار package.json کپی کنید.
فایل‌های هم‌نام را Replace کنید؛ پوشه پروژه و پوشه‌های assets/public موجود را حذف نکنید.
اصلاحات نسخه قبلی صفحه اصلی در ریپو حفظ شده‌اند و نیازی به برگرداندن ZIPهای قبلی نیست.

اجرا در ویندوز (برای جلوگیری از خطای IPv6/پورت قبلی):
npm run dev -- --host 127.0.0.1 --port 3000
آدرس Local نمایش‌داده‌شده در ترمینال را باز کنید.

بررسی و انتشار:
npm run check
npm run build:pages
git add .
git commit -m "Polish internal pages and add searchable product filters"
git push origin main

پس از موفق‌شدن GitHub Actions، صفحه را با Ctrl+F5 تازه کنید.
Dependency جدیدی اضافه نشده و package.json/package-lock.json تغییر نکرده‌اند.

گزارش، قرارداد بک‌اند و پیش‌نمایش‌ها:
